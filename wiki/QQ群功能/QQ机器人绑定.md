# QQ 机器人绑定系统

梦幻之屿的官方 QQ 机器人「琪露诺」驻扎在玩家 QQ 群与 QQ 频道中：QQ 群提供聊天转发、群内小游戏与远程查询，QQ 频道提供绑定与聊天转发。机器人并不认识游戏里的你——**绑定**就是把你的 QQ 身份与游戏账号对应起来。绑定之后，你在群里发出的指令都会以你的游戏身份执行：玩群内小游戏、查背包、领奖励，权限也与你的游戏账号完全一致。

## 一、绑定流程总览

绑定需要**双向确认**：先在 QQ 里声明要绑定哪个游戏名，再回到游戏内确认是你本人操作。只完成一半是不会生效的。

1. **第一步（QQ 群内）**：向机器人发送 `/bind 你的游戏名`（例如 `/bind Molean`）。
2. 机器人核对后，回复一串字符 ID，并提示下一步该怎么做。
3. **第二步（游戏内）**：进入服务器，在聊天栏输入 `/bind qq <那串ID>`。
4. 提示「绑定成功。」，即刻生效。

> 机器人回复的是一串 **32 位字符的标识，不是你的 QQ 号**（形如 `E4F4AEA33253A2797FB897C50B81D7ED`）。游戏内 `/assist` →「QQ群玩法」也提供了图形化入口，但那个弹窗只接受数字输入——如果机器人回复的 ID 里带字母，请直接在聊天栏输入完整 ID。

## 二、QQ 群绑定

### 触发方式

- 群消息以 `/` 开头即视为指令；也可以先 @机器人、再以 `/` 开头。
- 机器人响应其所在的**所有群**（聊天转发只限指定的主群，但指令在任何群都能用）。
- 指令不区分大小写。

### 第一步：`/bind <游戏名>`（QQ 群内）

- 按游戏名查找玩家，离线玩家同样可以绑定。
- 如果提示「你已经绑定过一个玩家。」，说明这个 QQ 已经绑过账号；
- 如果提示「这个玩家已经绑定了另一个QQ号。」，说明该游戏账号已被其他 QQ 占用。想换绑请先解绑（见第六节）。
- 通过后，机器人回复你的 ID，并提示你到游戏内输入 `/bind qq <ID>`。

### 第二步：`/bind qq <ID>`（游戏内）

- 进入游戏，在聊天栏输入机器人给出的完整 ID；系统会确认这条绑定确实由你本人在游戏内发起，然后绑定生效。
- 若提示需要先在群里操作，回到 QQ 群重新执行第一步即可。
- 绑定长期有效，重启服务器、跨天都不会失效。

## 三、QQ 频道绑定

QQ 频道的绑定流程与群类似，命令略有不同：

1. 频道内发送 `/bind <游戏名>`，机器人回复你的频道用户 ID；
2. 游戏内输入 `/bind <频道用户ID>` 完成绑定（**不带 `qq` 前缀**）；
3. 绑定成功后会同时获得频道的「认证玩家」身份组；如果绑定成功却没有身份组，可在频道发送 `/bind fix` 补办。

群与频道是**两套独立的绑定**，可以分别绑定、互不影响。频道目前提供绑定与聊天转发；群内小游戏（钓鱼、农场、挖矿、模拟炒股、每日签到）的指令只在 QQ 群可用。

## 四、手机号绑定（短信验证码）

与 QQ 无关、但同属 `/bind` 家族的第三种绑定方式：

- `/bind phone <手机号>`：发送 6 位短信验证码（仅限中国大陆手机号；手机号与玩家都不可重复绑定）。同一人 **60 秒冷却**、**最多发送 3 次**。
- `/bind verify <验证码>`：输入正确即完成绑定。**累计输错 10 次会永久锁定**手机号绑定，需联系管理员处理。
- 手机号绑定**没有自助解绑入口**。

## 五、绑定后的权益

| 权益 | 说明 |
|---|---|
| 群内小游戏 | 每日签到、挖矿、钓鱼、农场、模拟炒股、红包、今日宝箱等 |
| 远程查询 | `/money`、`/playtime`、`/rank`、`/背包`、`/末影箱`、`/player`、`/advancement` 等 |
| 远程交互 | `/tell <玩家> <消息>` 给游戏内玩家发私信、订阅/取消订阅等 |
| 权限一致 | 你在 QQ 侧能用的指令，与你游戏账号的权限完全相同——游戏里是管理员，群里也能用管理指令 |
| 聊天身份 | 群消息转发进游戏时显示你的**游戏ID**（未绑定者显示斜体群昵称） |
| 系统播报 | 炒股周报、临时 OP 等播报与你的账号关联 |
| 临时 OP | `/tempop <理由>`（需有对应权限），未绑定会被拒绝 |

未绑定时执行需要游戏身份的指令，会统一收到「仅玩家可执行该命令。」并附上用法提示。

## 六、解绑与换绑

| 场景 | 操作 |
|---|---|
| QQ 群解绑 | 群内发送 `/unbind` 或 `/bind unbind` |
| QQ 频道解绑 | 频道内发送 `/bind clear` |
| 手机号解绑 | 无自助入口，需联系管理员协助 |

**换绑 = 先解绑，再重新绑定一次**。解绑只解除对应关系，不影响游戏账号本身的任何数据与权限。

## 七、常见问题

**Q：机器人给的 ID 不是我的 QQ 号？**
A：这是正常现象。机器人只能拿到平台分配的匿名标识，绑定过程靠它来对应你的账号，请原样复制到游戏内使用。

**Q：提示「你已经绑定过一个玩家」/「这个玩家已经绑定了另一个QQ号」？**
A：说明其中一侧已存在绑定关系。先按第六节解绑旧关系，再重新绑定。

**Q：我在群里用了指令，回复「仅玩家可执行该命令」？**
A：说明当前 QQ 还没有绑定游戏账号，请先完成第一节的两步流程。

**Q：绑定后进群/进服发现身份组或身份不对？**
A：频道绑定可尝试 `/bind fix`；仍不正常请联系管理员协助核对。

## 八、命令一览

### QQ 群 / 频道侧

| 命令 | 平台 | 说明 |
|---|---|---|
| `/bind <游戏名>` | 群、频道 | 绑定第一步 |
| `/bind unbind` 或 `/unbind` | 群 | 解绑 |
| `/bind clear` | 频道 | 解绑 |
| `/bind fix` | 频道 | 补办认证身份组 |
| `/cm ...` | 群 | 指令规则管理（管理员） |

### 游戏内侧

| 命令 | 说明 |
|---|---|
| `/bind qq <QQ用户ID>` | 完成 QQ 群绑定（第二步） |
| `/bind <频道用户ID>` | 完成 QQ 频道绑定（第二步） |
| `/bind phone <手机号>` | 发送短信验证码（60 秒冷却、限 3 次） |
| `/bind verify <验证码>` | 完成手机号绑定（错 10 次锁定） |
| `/assist` →「QQ群玩法」 | 图形化绑定指引 |
