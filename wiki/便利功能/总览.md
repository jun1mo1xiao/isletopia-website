# 便利功能

本页集中介绍常规岛屿（经典空岛系）启用的一揽子便利机制。大多数功能可在游戏内「辅助功能」菜单或 `/assist` 命令中个人开关。

带个人开关的功能，统一使用 `/assist <开关名> true|false` 的形式切换（例如 `/assist DisableChairs true`）。

## 功能总览

| 功能 | 一句话介绍 |
| --- | --- |
| [自动铺路](/wiki/便利功能/自动铺路) | 副手持方块水平移动时，自动铺平脚下及前进方向的 3×3 区域 |
| [铁电梯](/wiki/便利功能/铁电梯) | 站在铁块上跳跃上行、潜行下行，无高度限制的垂直电梯 |
| [铁路传送](/wiki/便利功能/铁路传送) | 站在铁轨上按 Shift，沿轨寻路直达末端 |
| [举高高](/wiki/便利功能/举高高) | 双手皆空举起生物或玩家，可叠罗汉、蓄力投掷 |
| [时钟菜单](/wiki/便利功能/时钟菜单) | 持钟左键开主菜单、潜行左键回岛、右键开服务器菜单 |
| [更多椅子](/wiki/便利功能/更多椅子) | 低头长按 Shift 原地坐下，也可用 `/sit` |
| [音乐](/wiki/便利功能/音乐) | 音符盒音乐的播放、作曲与音乐包分享 |
| [首棵树苗](/wiki/便利功能/首棵树苗) | 生涯第一次破坏树叶额外掉落对应树苗 |
| [信标传送](/wiki/便利功能/信标传送) | 激活信标之间按距离排序的传送网络 |
| [回响扳手](/wiki/便利功能/回响扳手) | 潜行右键旋转楼梯、漏斗等数十种方块的朝向 |
| [岩浆保护](/wiki/便利功能/岩浆保护) | 空桶还原黑曜石、阻止毁岩浆的系列护栏 |
| [安全落点](/wiki/便利功能/安全落点) | 传送落点不安全时自动垫脚，杜绝摔死 |
| [伤害显示](/wiki/便利功能/伤害显示) | 攻击生物时的伤害飘字，按类型区分图标 |
| [邮箱](/wiki/便利功能/邮箱) | 接收系统与玩家寄送的物品与附件，无容量上限 |
