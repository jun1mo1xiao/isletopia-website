# 岛屿开关

梦幻之屿的特性分两层控制：**整岛开关**（写在岛屿上，影响所有在岛玩家，由岛主切换）与**个人开关**（只影响自己，用 `/assist` 切换）。本页不仅列出全部开关，还说明每个开关背后的实际机制——它拦住了什么、放行了什么、在什么边界下会失效。游戏内可用 `/menu feature` 打开「特性列表」查看当前岛屿的开关状态。

## 操作入口

- **整岛开关**：岛主使用下表中的命令，或在**岛屿设置**界面操作（从岛屿详情进入；`/openDialog /islands` 或 `/land of <玩家>` 打开岛屿详情）。设置界面里首次开启部分功能需要消耗海洋之心，命令通常只做切换。
- **个人开关**：`/assist <开关名> true|false`，或辅助功能界面 `/assists` 中切换。
- **查看说明**：`/menu feature` 列出当前岛屿全部特性与说明。

# 一、权限与保护

## 三重保护怎么判定

「三重保护」是一个整岛开关（常规岛屿默认开启），它把岛屿上的行为分成**三个域**统一按权限判定：

1. **方块域**：破坏、放置、玩家改变方块、实体形成方块（如霜行者）；
2. **实体域**：伤害实体、击退、载具伤害、盔甲架操作、破坏展示框/画、右键实体（村民交易、上马、剪羊毛等）；
3. **玩家域**：丢弃/拾取物品、拾取经验、怪物索敌、触发袭击、投掷投射物、载具碰撞。

判定链是「按优先级取第一个结果」，你可以把它理解成三道闸门：

- **白名单**（如游客交互白名单、实体保护开关）优先级最高，先放行特定行为；
- **三重保护**其次，把访客的其余行为全部拒绝；
- 更细的岛屿规则（如子领地）可以插在中间。

关键性质：

- 岛主与成员一律放行；**访客默认被拒绝**（不是"未定义"，而是明确拒绝）；
- 判定看**事件发生的位置**：伤害按受害者所在岛判定，方块交互按方块所在岛判定；
- **OP 不会豁免**（除了个别开关如锁岛、旁观访客明确给了 OP 豁免）；
- 「信任所有人」开关会把任何人视为成员级权限（管理端设置，无玩家命令）。

## 权限矩阵

三重保护开启、未配置任何白名单时：

| 行为 | 岛主 | 成员 | 访客 |
| --- | --- | --- | --- |
| 破坏/放置方块、改变方块 | ✅ | ✅ | ❌ |
| 右键方块（拉杆、按钮、门、床、容器） | ✅ | ✅ | ❌ |
| 使用物品（右键空气/烟花/珍珠/钓竿等） | ✅ | ✅ | ❌ |
| 伤害/击退实体、载具与盔甲架操作、破坏展示框 | ✅ | ✅ | ❌ |
| 右键实体（交易、上马、剪羊毛、旋转物品框） | ✅ | ✅ | ❌ |
| 丢弃物品、拾取物品/箭/经验、中键取方块 | ✅ | ✅ | ❌ |
| 被怪物索敌、触发袭击 | ✅ | ✅ | ❌（怪物不会锁定访客） |
| 投掷投射物（箭、珍珠、雪球） | ✅ | ✅ | ❌ |
| 水桶倒水/收水、玩家引发的爆炸（床、重生锚） | ✅ | ✅ | ❌（且非岛屿世界一律禁止） |

补充规则：

- **访客死亡默认保留物品**：死亡不掉落的默认值按「是否有岛权限」计算，所以访客在别人岛上摔死不会爆装备（详见「死亡与重生规则」）；
- 黑名单玩家与普通访客在保护判定上一致，区别只在「能不能进岛」；
- 苦力怕/爆炸对建筑的破坏不由身份决定，而由防爆开关决定（见下文）。

## 访客开关与白名单

岛主可以在「保护开着」的前提下，给访客精确放行某些行为：

| 开关 | 放行的行为 | 细节 |
| --- | --- | --- |
| `/ToggleAllowItemPickup` | 拾取掉落物、箭、经验、中键选取方块 | 真正可开可关 |
| `/ToggleAllowItemDrop` | 丢弃物品 | 当前实现下关不回去（见「已知边界」） |
| `/ToggleAllowFirework` | 使用烟花火箭 | 同上 |
| `/AllowInteractBlocks add\|remove <方块>` | 允许访客右键指定方块（如工作台、按钮） | 按方块材质逐项放行 |
| `/AllowUseItems add\|remove <物品>` | 允许访客使用指定物品 | 按物品材质逐项放行 |
| `/ToggleDisableEntityProtect` | 关闭整类实体交互保护：访客可右键物品、攻击实体、被怪物索敌、触发袭击、投掷投射物、操作载具/盔甲架等 | 只影响实体类事件，**不影响方块破坏/放置**，也不影响白名单逻辑 |

选择逻辑：**想和访客互动（比如让朋友用工作台），优先用白名单；想办活动（让所有人在岛上自由战斗），才用实体保护开关。**

## 锁岛、黑名单、旁观访客

- **锁岛** `/Lock Lock`：非成员**传送进岛会被拒绝**；已经待在岛上的非成员会被送回自己的第一座岛。成员与岛主不受影响，OP 豁免。解锁用 `/Lock Unlock`。
- **黑名单** `/blacklist add <玩家>`：被拉黑者传送进岛被拒、逗留时被送回自己的岛；**成员被拉黑也会被踢**。岛主与 OP 豁免。
- **旁观访客** `/ToggleSpectatorVisitor`：非成员进入该岛时游戏模式被强制为**旁观**，离开岛屿或成为成员后自动恢复（逐 tick 校验）；旁观状态下不能用旁观者附身/传送到实体。OP 与该岛管理员权限者不受影响。
- **信任所有人**：管理端开关，开启后任何人都获得成员级权限（三重保护全放行）。没有玩家命令，且**不能**绕过锁岛的落地检查。

# 二、世界行为开关详解

## 防爆开关 `/ToggleDisableCreeperExplode`

机制细节比名字复杂：

- 只拦**苦力怕**与**玩家引发**（床、重生锚）的爆炸对**方块的破坏**，TNT 不在保护范围内；
- **对实体的伤害不拦**——爆炸对玩家/生物照常造成伤害与击退，只是不留坑；
- 展示框与画会额外单独保护，不会被苦力怕炸掉；
- 自定义名为 `Creeper` 的苦力怕被显式豁免——这是给「命名苦力怕爆头」机制留的口子；
- 在非岛屿世界里，苦力怕/玩家爆炸对建筑的破坏**一律被禁**。

## 防火 `/ToggleAntiFire`

- 拦截两类事件：**方块被烧毁**与**点燃**。点燃不区分来源——火蔓延、打火石、闪电、火球、岩浆引燃全都算；
- **不拦**实体身上的火焰伤害，也不拦火焰的自然熄灭；
- 原版火焰蔓延规则本身是开启的，防火开关是在此之上叠加的拦截层；
- 在非岛屿世界里，点燃与方块燃烧是**全局禁止**的；
- 与 `/ToggleAntiPhantom` 一样，命令只切换已有开关；首次开启需在岛屿设置界面消耗 1 海洋之心。

## 防幻翼 `/ToggleAntiPhantom`

- 生成时直接取消：不区分生成原因，刷怪笼、`/summon` 也会被拦；
- **对已经存在的幻翼不做处理**（不会清场）；
- 非岛屿世界永远不生成幻翼；
- 首次开启消耗 1 海洋之心。

## 禁自然刷怪 `/ToggleDisableNaturalSpawning`

- 实现层级更深：它不逐个判断生物，而是**直接掐停"玩家附近区块的自然刷怪循环"**，因此所有类别（怪物、动物、水生、环境）都不再自然刷新；
- **不受影响**：刷怪笼、刷怪蛋、繁殖、结构自带生物、`/summon`、袭击/巡逻队/幻翼（这些走独立逻辑）；
- 开关生效有约 2 秒缓存延迟，对该岛三个维度同时生效。

## 全岛史莱姆区块 `/ToggleAllSlimeChunk`

- 开启后，该岛所有区块都按史莱姆区块的规则参与生成判定（原版判定被整体替换）；刷怪笼产出的史莱姆不受影响；已是原版史莱姆区块的位置概率更高；
- **注意**：`/slime` 查询显示的是**原版种子算法**的史莱姆区块，不反映这个开关——开启全岛史莱姆区块后 `/slime` 依旧一片空白，这是正常的。

## 禁止幻形 `/ToggleDisableNeeko`

- **禁止新变身**：在本岛无法使用[幻形](/wiki/特殊功能/幻形)（提示「当前岛屿无法使用幻形」）；
- **已有幻形者会被自动解除**并提示退回玩家；离开该岛后按存档自动恢复；
- 切换开关的瞬间会对岛上所有玩家立即生效（不只是进出岛时检查）；
- 非岛屿世界不限。

## 游商加速

惊变空岛默认启用（值为 4）：把游商刷新逻辑**每个游戏刻连续执行 4 次**，整体节奏约快 4 倍（刷新周期从约 20 分钟缩短到约 5 分钟，概率爬升也同步加快）。普通岛屿没有这个开关，也没有对应命令。

## 死亡与重生规则

- **整岛死亡不掉落**（KeepInventory）：默认在常规岛屿、SMP、单方块、惊变等开启。开启时**物品、等级、经验全部保留**；
- 关闭该开关时按身份区分：**成员/岛主正常掉落；访客默认保留**（没有岛权限的人不会因死在别人岛上而丢东西）；非岛屿世界（大厅等）默认保留；
- **个人开关的现状**：`/assist DisableKeepInventory` 界面与命令都在，但当前版本没有读取它的逻辑——也就是说目前**无法个人关闭**死亡不掉落；
- **死亡消息范围**：开启本岛限定后，死亡消息只发给**同一座岛（三个维度）内的玩家**；开关关闭或死在非岛屿世界时，死亡消息**谁都看不到**（包括死者自己）。

# 三、世界设置与设施

## 下界传送比例 `/TeleportationScaleSet <1|8>`

- 只作用于**原版下界传送门**的坐标换算与找门搜索：比例 = 源维度系数 ÷ 目标维度系数，默认主世界 1.0、下界 8.0、末地 1.0，即经典 1:8；
- 改成 1 即 1:1；命令只接受 8 或 1，末地系数不可改；
- **不影响** `/visit`、`/spawn`、`/land tp` 等岛屿传送命令；
- [地底世界](/wiki/空岛类型/地底世界)移除了该开关的数据，坐标换算仍按默认 1:8 执行。

## 群系与生成设置

| 设置 | 说明 | 谁会用到 |
| --- | --- | --- |
| `/BiomeSet <群系>` | 设置当前维度全岛的单一群系（主世界/下界/末地分别校验，禁止 CUSTOM） | 常规岛屿（地底世界除外） |
| GeneratorSettings（6 项） | 噪声地形/地表/洞穴/装饰/生物/结构六项生成开关，逐项启用 | SMP 全开；海底求生只开结构；地底世界全开 |
| GenerateStructures | 只开结构生成 | 困难空岛、海底求生、惊变 |
| EnableEndGen | 末地完整地形生成 | 仅海底求生 |
| 岛屿时间 / 天气 / 随机刻速度 | 已实现但**没有玩家命令**，仅活动与管理场景使用 | — |

## 信标传送 `/BeaconTeleport`

- **使用条件**：潜行时**站在一台激活的真实信标正上方**（金字塔等级 ≥1 且有光束）；
- **搜索算法**：从所在区块出发，沿四个方向在**连续已加载的区块**内广度搜索其他激活信标（不加载新区块、不跨世界）；目的地需信标仍激活且上方两格为空气；
- **界面**：每页 12 个，显示信标名称、坐标、金字塔等级、基座材质，按距离排序；
- **无消耗、无冷却**；传送瞬间为目标区块上票据防止卸载；离开源信标或目标失效会取消并提示；
- 开关为本岛开关，非本岛信标不参与搜索。

## 全岛信标

命令：`/HexBeacon enable|disable <效果>`。

- **与真实信标结构无关**：只要玩家身处该岛世界，效果每 3 秒刷新一次（持续 5 秒），等效于全岛常驻；
- 可解锁效果与等级：速度、急迫、力量、跳跃提升、抗性提升为 **II 级**；生命恢复为 **I 级**；
- **解锁经济**：每个效果首次解锁消耗 1 颗海洋之心，之后启停免费，解锁永久保存；
- **附魔信标**：岛上有 6 星[鹦鹉幻形](/wiki/特殊功能/幻形图鉴)玩家时，全岛效果等级 +1（持续 60 秒，可反复触发）；
- 管理端可用 `/isa hexbeacon set|enable|disable|remove` 直接配置。

## 人造末地门

- 每座岛有一个**确定性生成**的末地门坐标（由岛屿种子决定，主世界 Y=50）；
- 投掷末影之眼时，寻路目标被强制指向该坐标；**当末影之眼生成点距门心 64 格内**，门心处会显现出 **12 个末地传送门框架**（5×5 缺四角的环、朝向朝内、不带眼睛）——这是幂等的，重复投掷不会破坏，但会**覆盖该位置原有方块**；
- `/toggleRelocateEndPortal` 切换「进入末地的出口是否重定向到本岛门旁」。注意该开关默认关闭，且受命令写入语义影响，**需要执行两次才能开启**（第一次写入关闭状态，第二次写入开启）；
- 无论是否开重定向，**从末地返回主世界**始终回到本岛 (256, 地表, 256) 附近。

## 区域结构与结构放置

- **区域结构** `/RegionStructure add|clear|list`：手持箭矢左键/右键选两点圈出区域，指定一种结构。**它不会真的生成结构方块**，而是让该区域按对应结构的刷怪表刷怪（2 秒内生效，无需重载区块）；
  - 可用结构：主世界 前哨站/女巫小屋/海底神殿；下界 下界要塞/堡垒遗迹；
  - 命令可添加任意条；图形界面（岛屿设置 → 自定义结构）上限 **3 条**；
- **放置结构** `/placestructure <结构>`：在[困难空岛](/wiki/空岛类型/困难空岛)等李芒果模式中，**击杀末影龙**可解锁 5 次放置额度（每种结构 1 次），岛主可把真实结构放到自己脚下；结构 key 来自完整结构注册表，放置前会检查目标区域是否加载。

# 四、个人开关（`/assist`）

| 子命令 | 效果 |
| --- | --- |
| `/assist AutoFloor true\|false` | [自动铺路](/wiki/便利功能/自动铺路) |
| `/assist DisableRailWay true\|false` | [铁路传送](/wiki/便利功能/铁路传送) |
| `/assist DisableIronElevator true\|false` | [铁电梯](/wiki/便利功能/铁电梯) |
| `/assist DisablePlayerRide true\|false` | [举高高](/wiki/便利功能/举高高) |
| `/assist DisableChairs true\|false` | [更多椅子](/wiki/便利功能/更多椅子) |
| `/assist DisableLavaProtect true\|false` | [岩浆保护](/wiki/便利功能/岩浆保护) |
| `/assist DisableKeepInventory true\|false` | 关闭自己的死亡不掉落（有二次确认；当前版本未生效，见上文） |
| `/assist DisableAdvancedTell true\|false` | 高级私信开关（当前版本未生效） |
| `/assist mailbox` | 打开[邮箱](/wiki/便利功能/邮箱) |
| `/assist Recycle` | 打开垃圾桶 |
| `/assist Slime` | 查找史莱姆区块（显示原版区块） |
| `/assist reduceEntityPacket <0-100>` | 实体包削减（性能向） |
| `/assist ExtendViewDistance` | 视距 +1（消耗 1 海洋之心，上限 32） |

辅助功能界面里还有一批纯界面开关：TPS 栏、血量条、各种提示条与侧边栏、岛屿聊天前缀、旧版菜单等。

## 个人开关的实际行为

所有个人开关都以 `/assist <名称> true|false` 的形式写入，`true` 表示**禁用**对应便利功能（命名沿用 `DisableXxx`）。当前版本的行为注意：

- 铁路传送、铁电梯、举高高、椅子、岩浆保护、自动铺路六个开关**真实生效**；
- `AutoFloorLegacy` 写入的值没有任何读取方，等于没开——用 `AutoFloor`；
- `DisableKeepInventory`、`DisableAdvancedTell` 目前**只写不读**；
- 铁电梯、举高高、椅子、岩浆保护的前置条件见[便利功能](/wiki/便利功能/总览)。

# 五、未开放的开关与已知边界

以下特性代码已实现，但**没有挂载到任何常规岛屿类型**（管理端可为活动岛手动开启），列此仅供了解：

| 类别 | 特性 |
| --- | --- |
| 方块控制 | 禁止破坏/放置方块、禁止方块燃烧/消退/形成、禁止珊瑚死亡、禁止冰雪融化、禁止火焰蔓延与熄灭、禁止树叶凋零、禁止液体流动、禁止物理更新 |
| 实体控制 | 禁止生物/实体/怪物生成、禁止爆炸、禁止 PvP、禁止鞘翅、禁止玩家投掷物、禁止随机巡逻队、禁止骷髅陷阱、禁止海龟蛋孵化、禁止流浪商人生成 |
| 世界控制 | 禁止红石、区域群系 `/RegionBiome`、全岛单结构 `/StructureSet`、高级发射器 `/ToggleSuperDispenser`、随机复活点、Tab 列表隐藏 |
| 功能类 | 自动补种、经验泳池、岛屿飞行、随机烟花、服务器资源包推送、区块刷新器 |
| 安全类 | 封岛（带理由）、区域 CPU 限时、禁止区块存盘 |
| 其他 | 信任所有人（管理端）、区域系统 `/district` |

其中「禁止骷髅陷阱」「全岛单结构」「高级发射器」「区域群系」有命令入口但调用会提示当前不可用；个别未开放类存在实现异常（例如火焰相关开关的判定错位），实际启用前需管理员确认。

## 用户可感知的已知边界

- `/ToggleAllowItemDrop`、`/ToggleAllowFirework` 关闭后访客仍能丢弃/放烟花（当前仅能通过管理端移除开关恢复默认）；
- `/slime` 与全岛史莱姆区块开关无关；
- 「关闭实体保护」后，访客的**投射物伤害与对生物的击退**仍会被保护拦下（实现覆盖不全）；
- 锁岛、黑名单的行为对成员、OP 的豁免规则见上文。

# 管理端

管理员可用 `/isa`（权限 `isletopia.isa`）直接读写任意岛屿的 flag、封岛/解封、设置岛屿标题、发放结构额度、配置全岛信标等；Web 后台也有等价的 flag 读写接口。岛屿级别的开关数据每 5 秒批量落库。
