# 粘液科技

粘液科技（Slimefun）是[粘液科技空岛](/wiki/空岛类型/粘液科技空岛)的核心玩法——一个庞大的「模组化」科技树插件：数百种新物品、机器与自动化产线，从基础工作台一路研究到核能、货运网络与魔法装置。

## 在本服的运作方式

- 粘液科技**只在粘液科技空岛上启用**。其他任何岛屿类型的世界里，粘液科技物品与机制全部不生效。
- 创建粘液科技空岛后会自动打开粘液指南书（`/sf guide`），一切研究从这里开始。
- 研究解锁需要消耗**大量经验与金币**，解锁条件苛刻，不建议新手直接上岛。

## 存档与仓库

- 粘液空岛使用独立的 `Slimefun` 存档档案（背包、末影箱、经验与普通模式隔离，见[岛屿管理](/wiki/便利功能/岛屿管理)的 Profile 说明）。
- 但云仓档案与普通模式共用 `default`，即**云仓物资可以带入粘液空岛使用**。

## 特殊规则

- **无幻形**：粘液空岛移除了[幻形](/wiki/特殊功能/幻形)系统，进入时幻形自动解除。
- **无刷石机出矿命令**：矿石获取走粘液科技自己的产线（如矿石粉碎机、淘金系统）。
- **允许超限附魔**：粘液科技的部分物品附魔等级会突破原板上限，在本岛不受非法物品审计限制。
- 常规特性照常生效：[空岛挑战](/wiki/特殊功能/挑战任务)、[空岛合成配方](/wiki/资源获取/空岛合成配方)、[祈愿池](/wiki/特殊功能/祈愿池)、[便利功能](/wiki/便利功能/总览)等均可用。

## 上手路线

1. 跟随指南书完成「基础机器」章节：增强型工作台 → 冶炼炉 → 压力机；
2. 建立矿物处理产线（矿石粉碎机 + 洗矿槽），解决基础资源；
3. 逐步解锁电力时代：发电机 → 电容 → 电动机器；
4. 最终走向货运自动化、核能与高端装备。
