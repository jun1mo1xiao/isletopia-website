# 玩家系统

本页集中介绍梦幻之屿围绕**玩家个人**运转的各项系统：服务器菜单、聊天与社交、成就与进度、辅助功能、各类查询指令，以及挂机状态等杂项。

岛屿本身的玩法与指令见[岛屿系统](/wiki/系统功能/岛屿系统)；经济货币见[经济系统](/wiki/系统功能/经济系统)；QQ 账号绑定的完整流程见[QQ 机器人绑定系统](/wiki/QQ群功能/QQ机器人绑定)。

## 一、游玩流程总览

梦幻之屿没有主城大厅，一位玩家的日常动线大致如下：

1. **第一站是「服务器菜单」**：按 `G`（1.21.6+）打开，岛屿、任务、个人信息、辅助功能、经济、活动等入口都在这里。低版本客户端可用 `/menu` 或时钟 `/clock` 打开菜单。
2. **随时说话**：直接在公屏输入文字即可；想让某人注意到你，在消息里写上他的名字；`#岛屿编号` 可以把岛屿分享成可点击的链接。
3. **社交**：`/tell` 私聊；`/关注 <玩家>` 常一起玩的人，对方上下线会提醒你。
4. **绑定 QQ 群**（可选但推荐）：游戏与 QQ 群的聊天双向互通，还能在群里远程查询数据、签到，玩钓鱼、农场、挖矿、炒股等群玩法。
5. **推进度**：任务走 `/quest`；成就勋章在「我的信息 → 成就勋章」；想要侧边栏统计面板就去「辅助功能 → 数据统计」。
6. **善用「辅助功能」**：个人开关、邮箱、云仓、音乐包、特性百科等都从这里进入，对应命令大多是 `/assist` 的子命令。
7. **需要数据时**：游戏内用 `/player`、`/money` 等命令；更全的查询（背包、末影箱、时长、排行）在 QQ 群里。
8. **挂机也有讲究**：长时间不操作会被标记为「💤 挂机中」，视距与实体同步量自动降低；主动挂机用 `/afk`。

新版服务器菜单是几乎所有功能的统一入口：

| 按钮 | 打开的内容 |

| ☺ 我的信息 | 我的岛屿、成就勋章、海洋之心、电费账单、幻形等 |
| ☰ 玩家菜单 | 在线玩家列表、玩家信息、我的关注列表（`/players`） |
| ✎ 任务系统 | 查看并追踪任务进度、领取任务奖励（`/quest`） |
| ⚙ 辅助功能 | 邮箱、云仓、音乐包、功能选项等实用工具（`/assists`） |
| ♦ 经济中心 | 海洋之心、金币排行、统计排行、税收中心 |
| ✎ 功能百科 | 服务器全部特性的说明与用法 |
| ✦ 活动中心 | 极限生存挑战、小游戏活动、论坛顶贴、NameMC 点赞、MCMOD 评分 |
| ⚙ 管理 | 管理菜单（仅管理员可用） |
| ✉ QQ群 | 点击加入官方 QQ 群 |
| ✍ 意见反馈 | 打开反馈平台 |
| 旧版菜单 | 打开旧版箱子菜单（`/menu`，即将弃用） |

### 其他入口

- `/menu`：旧版箱子式主菜单；另有 `/menu recipe`（扩展合成表）、`/menu feature`（特性列表）、`/menu close`。
- `/clock`：领取"主菜单"时钟，左键开菜单、潜行左键回岛、右键开新版菜单（详见[便利功能 · 时钟菜单](/wiki/便利功能/时钟菜单)）。
- `/openDialog <路径>`：直接打开任意界面，例如 `/openDialog assists`，适合记不住按钮位置时直达。
- 新版与旧版界面可以随时切换：辅助功能 → 功能选项 → 「尽可能使用旧版/新版菜单」。新版界面支持返回上级、回到首页与分页浏览。

## 三、聊天系统

梦幻之屿的公屏聊天由服务端自行渲染：你输入的颜色代码与格式符号不会被解析生效，但同时自带一批快捷识别功能。

### 一条消息的组成

默认格式为 `[岛屿前缀] <玩家名> 消息内容`：

- 玩家名为白色；若发送者所在岛设置了**岛屿聊天前缀**，名字前会带灰色的 `[前缀]`。点击该前缀可打开对应岛屿的界面，悬停显示岛屿信息；你可以在「功能选项」里关掉自己的前缀显示。
- **悬停玩家名**：显示玩家档案（加入时间、岛屿数量、勋章积分、金币、原版进度、游戏时长、海洋之心、佩戴的勋章、幻形等级）。
- **点击玩家名**：打开该玩家的信息面板。
- 关注了发送者时，他的名字对你显示为青蓝色（见[四、私聊与关注](#四、私聊与关注)）。
- 来自 QQ 群的消息会带灰色前缀：未绑定用户显示 `[聊天频道]`；绑定用户按游戏内规则显示其岛屿前缀（无前缀时回退为 `[聊天频道]`）。

### 消息里的快捷识别

| 消息里出现 | 效果 |
| --- | --- |
| 在线玩家名（无需 `@`） | 高亮为灰色，点击打开该玩家面板，悬停显示档案 |
| `#123`（岛屿编号） | 显示为「岛名(#123)」，点击打开岛屿面板 |
| `av123` / `BV1xx…` / `cv123` | 自动变成可点击的 B 站链接 |
| `@作者:曲名@` | 变成可点击的曲目，点击即可播放（详见[便利功能 · 音乐](/wiki/便利功能/音乐)） |
| QQ 群转发的图片/附件 | 显示为可点击的 `[图片]` / `[附件]` |

### 关键词快捷链接

消息中出现下列关键词时会自动变成可点击项（出现在消息任意位置都有效）：

| 关键词 | 点击效果 |
| --- | --- |
| `菜单` | 打开旧版菜单 |
| `特性` | 打开特性列表 |
| `新合成表` | 打开扩展合成表 |
| `新手教程` / `新手教学` / `怎么玩` | 打开新手教程合集 |
| `QQ群` / `群号` | 打开加群链接 |
| `顶贴` / `顶帖` / `兔小巢` / `反馈` | 打开反馈平台 |
| `点赞` | 打开 NameMC 服务器点赞页 |
| `捐助` | 打开爱发电页面 |

其中前三个会直接为你执行对应命令并打开界面，其余为网页链接。此外，管理员可以在 QQ 端扩充问答词库，新增词条同样会在聊天中生效。

### 发言限制

- **防刷屏**：30 秒内，同一段相似消息从第 3 条起会被拒绝，并提示 `[危险警告]不要刷屏!`（高度相似的短消息也会被判定为重复）。
- **新玩家审核**：发言天数较少的账号，每条发言会经过内容安全审核；这类账号每天发言达到 1000 条后会被限制继续发言。
- **禁言**：被管理员禁言后，发言会提示 `你已被禁言至<日期时间>!`。
- 从 QQ 群转发进游戏的消息不经过上述过滤。

### 聊天记录

- 游戏内不提供查询历史聊天记录的命令。
- 所有公屏消息（含 QQ 转发消息）都会入库；在 QQ 群里可以用 `/总结` 让机器人总结最近的聊天：
  - `/总结`——总结最近 1 小时；
  - `/总结 近期 PT2H`——按 ISO-8601 时长总结（上限 24 小时，如 `PT30M`、`PT2H30M`）；
  - `/总结 数量 1000`——总结最近 1000 条（默认 500，最多 2000）。

## 四、私聊与关注

### 私聊（`/tell`）

- `/tell <玩家> <消息>`，别名 `/msg`、`/w`；对方必须在线。
- 聊天框显示为 `<你的名字> -> <对方名字>: 消息`。
- "事务"模式：`/tell transaction <玩家>` 开启后，发给该玩家的消息会先累积不发送；`/tell commit <玩家>` 一次性发出全部累积内容。
- 绑定 QQ 后，在 QQ 群里也可以用同样的 `/tell` 私聊游戏内的玩家。

### 关注

关注是**单向**的，用来追踪你常一起玩的人：

- `/关注 <玩家>`（别名 `/subscribe`、`/收藏`）、`/取消关注 <玩家>`（别名 `/unsubscribe`）、`/关注列表`（别名 `/collections`）；完整写法还有 `/collections add|remove|list`。
- 关注后：
  - 对方发言时，他的名字对你显示为**青蓝色**；
  - 对方上线/下线时，你的动作栏会收到提示（`X上线了` / `X下线了`）。
- 在玩家信息面板里也可以直接点「♥ 关注 / ✕ 取消关注」。

## 五、与 QQ 群的互通

绑定 QQ 后（绑定方式见 [QQ 机器人绑定系统](/wiki/QQ群功能/QQ机器人绑定)；游戏内也可从「辅助功能 → QQ群玩法」查看引导），游戏与官方 QQ 群之间聊天双向互通：

- **游戏 → QQ 群**：你在游戏中的公屏发言会同步到 QQ 主群，显示为 `<你的游戏名> 消息`。
- **QQ 群 → 游戏**：主群的普通聊天会同步进游戏。绑定过的账号以游戏名身份显示；未绑定的 QQ 用户以斜体 QQ 昵称显示，并带 `[聊天频道]` 前缀。
- **不会同步的内容**：以 `/` 开头的指令消息、@机器人的消息。
- **内容转换**：图片/附件显示为可点击的 `[图片]` / `[附件]`；QQ 表情转为 `[表情名]` 文字；消息过长会被截断。

## 六、成就系统

游戏里有两条并行的"成就"：服务器自建的**成就勋章**，与**原版进度（Advancement）**。

### 成就勋章

- **查看**：打开玩家信息面板（`/player <玩家>`，或从「我的信息」进入），点「✔ 成就勋章」；面板只列出该玩家**已获得**的勋章，悬停可看描述、获取方式与勋章积分。
- **佩戴**：最多同时佩戴 **5 枚**。
  - `/achievement gui` 打开佩戴界面，点击勋章切换佩戴状态（已佩戴的带附魔光效）；
  - 也可用 `/achievement display <勋章>` 与 `/achievement undisplay <勋章>`。
  - 佩戴的勋章会显示在玩家档案的「佩戴的勋章」一栏。
- **积分**：每枚勋章有各自的积分，「勋章积分」为已获得勋章积分之和，显示在玩家档案里。
- **获取方式**：绝大多数勋章由管理团队根据活动、宣传与社区贡献发放；另有两枚可以通过游戏行为自动获得的稀有功勋，做法见[特殊生物与掉落](/wiki/资源获取/特殊生物与掉落)。
- 获得勋章时没有全服播报，也不会发送提示消息——想知道自己拿到了什么，去成就勋章页看看。
- 勋章是荣誉收藏，不提供数值加成。

### 原版进度

- 服务器启用原版成就系统，按 `L` 键即可打开进度界面；完成时只有你自己的客户端会弹出提示，不会全服播报。
- 玩家档案中的「原版进度: 已完成/总数」只统计真正的成就，不含配方解锁。
- QQ 群里可远程查询进度（别名 `/成就`、`/advancement`）：
  - `/进度 <玩家>`——列出该玩家完成的所有进度；
  - `/进度 <进度名>`——列出全服完成该进度的玩家，以及最先达成的玩家排名；
  - `/进度 <玩家> <进度名>`——查询某人某个进度的达成情况与时间。

### 与活动相关

[极限生存挑战](/wiki/空岛类型/极限生存挑战)拥有独立的 L 键成就树；[挑战任务](/wiki/特殊功能/挑战任务)中也有以成就为目标的收集类任务。

## 七、辅助功能

「辅助功能」是玩家的个人设置与工具中心。

### 打开方式

- 按 `G` → 「⚙ 辅助功能」；
- 或使用命令 `/openDialog assists` 直达。

界面里的部分按钮依赖当前岛屿开启对应特性：未开启时按钮会带上删除线，并标注「当前岛屿不可用」（如「我的幻形」「我的邮箱」）。

### 菜单内容

| 按钮 | 作用 |
| --- | --- |
| ☺ 我的幻形 | 查看和管理幻形皮肤（见[幻形](/wiki/特殊功能/幻形)） |
| ✦ 数据统计 | 选择侧边栏统计面板（见[九、杂项](#九、杂项)） |
| ⚙ 功能选项 | 坐下、电梯、自动铺路等个人开关，详见下方 |
| ⛏ 查找史莱姆区块 | 打开史莱姆区块查找器 |
| ✉ 我的邮箱 | 查看邮箱中的邮件，详见下方 |
| ☁ 云仓 | 跨岛屿云端仓库（见[云仓](/wiki/便利功能/云仓)） |
| ♫ 音乐包 | 浏览并更换背景音乐包 |
| ♻ 垃圾桶 | 打开垃圾回收站 |
| ⚒ 新合成表 | 浏览扩展合成表（见[空岛合成配方](/wiki/资源获取/空岛合成配方)） |
| ✉ QQ群玩法 | QQ 绑定指引与群玩法入口（签到、钓鱼、挖矿、农场等） |

### `/assist` 命令

以上大部分工具与开关都能用 `/assist` 命令操作。开关名**大小写不敏感**，布尔参数必填：

| 命令 | 作用 |
| --- | --- |
| `/assist mailbox` | 打开邮箱 |
| `/assist Recycle` | 打开垃圾回收站 |
| `/assist Slime` | 显示周边史莱姆区块 |
| `/assist AutoFloor <true\|false>` | 自动铺路开关 |
| `/assist DisableRailWay <true\|false>` | 铁轨传送开关 |
| `/assist DisableIronElevator <true\|false>` | 铁块电梯开关 |
| `/assist DisablePlayerRide <true\|false>` | 举起生物开关 |
| `/assist DisableChairs <true\|false>` | 随地坐下开关 |
| `/assist DisableLavaProtect <true\|false>` | 岩浆保护开关 |
| `/assist DisableKeepInventory <true\|false>` | 死亡不掉落开关（关闭时弹出二次确认） |
| `/assist DisableAdvancedTell <true\|false>` | 高级私信开关 |
| `/assist AutoFloorLegacy <true\|false>` | 旧版自动铺路模式（兼容旧设置） |
| `/assist reduceEntityPacket <0-100>` | 削减实体包发送（0 为关闭，数值越大越省流量） |
| `/assist ExtendViewDistance` | 视距 +1，消耗 1 颗海洋之心，上限 32 |

- 直接输入 `/assist` 会列出全部子命令与说明；设置成功会收到 `OK`。
- 各便利功能的玩法细节见[便利功能](/wiki/便利功能/总览)，全部开关的总览见[岛屿开关](/wiki/便利功能/岛屿开关)。

「功能选项」集中管理个人的界面与提示偏好。所有选项默认为"未开启"状态——即功能类默认启用、提示条类默认关闭、菜单默认新版：

| 选项（成对切换） | 效果 |
| --- | --- |
| 随地坐下 | 开关 `/sit` 与低头长按 Shift 坐下（见[便利功能 · 更多椅子](/wiki/便利功能/更多椅子)） |
| 铁轨传送 | 开关铁轨 Shift 传送 |
| 铁块电梯 | 开关铁块电梯 |
| 举起生物 | 开关举起/投掷生物 |
| 岩浆保护 | 开关岩浆保护护栏 |
| 死亡不掉落 | 背包保护开关；通过命令关闭时会弹出红色二次确认：「你正在关闭背包保护，关闭后，死亡将掉落所有物品，请谨慎开关。」 |
| 自动铺路 | 开关自动铺路 |
| 高级私信 | 高级私信开关 |
| TPSBar | 岛屿 TPS / 负载 Boss 条（快捷命令 `/tpsbar`） |
| HealthBar | 注视生物时显示血量条（快捷命令 `/healthbar`，别名 `/hb`） |
| 小游戏相关内容 | 不参与时不再收到小游戏通知，也不会被自动匹配进小游戏 |
| 极限活动侧边栏 | 极限生存活动的侧边栏开关 |
| 惊变侧边栏 | 惊变空岛的侧边栏开关 |
| 常闇侵蚀提示条 | 幽匿侵蚀的提示条开关 |
| 聊天栏名前游戏模式前缀 | 隐藏聊天里自己名字前的 `[岛屿前缀]` |
| 使用旧版/新版菜单 | 切换新旧界面风格（影响岛屿、云仓、邮箱等多处按钮布局） |

### 邮箱

- **发送**：`/mail <玩家> [留言]`——打开一个 27 格界面，把要送的东西放进去，**关闭界面即发送**；留言默认「一点心意」。不能给自己发；空箱子不会发送。
- **接收**：`/assist mailbox` 或「辅助功能 → 我的邮箱」，每页显示 15 封，点击邮件即领取。
- **提示**：对方在线时会收到「X 刚刚给你发送了一个包裹.」；有未领取的邮件时，登录会有提醒。
- **规则**：邮箱没有容量上限；发送与领取都要求当前岛屿开启邮箱功能。
- **常见邮件来源**：玩家互寄、商店退货、云仓退件（无法入库的物品）、QQ 群玩法奖励等。

## 八、查询指令

### 游戏内

| 命令 | 说明 |
| --- | --- |
| `/player <玩家>`（`/玩家`、`/玩家信息`） | 打开玩家信息面板 |
| `/uuid <玩家>` | 查询玩家 UUID；`/uuid of <UUID>` 反查名字 |
| `/money <玩家>` | 查询金币 |

## 九、杂项

### 挂机与状态显示

- 长时间没有操作会被自动判定为挂机；也可以用 `/afk` 主动标记。
- 判定后名字旁会出现灰色后缀：
  - `💤 挂机中`——已判定挂机；
  - `🤔 思考中`——长时间没有活跃行为，但尚未判定为挂机。
- 挂机期间视距会被缩小，实体、音效、粒子的同步量也会大幅降低（你会明显感觉"周围变安静"）；恢复操作后自动还原。
- 挂机玩家不会被自动匹配进小游戏。
- 当你正在做某件事时（挖掘、钓鱼、附魔、建造……），名字后缀会显示当前行为，如 `⛏ 挖掘中`、`🎣 钓鱼中`、`✨ 附魔中`。

### 侧边栏统计面板

用「辅助功能 → 数据统计」或 `/bar` 命令为自己开启侧边栏统计（默认为关闭）：

- `/bar set <类型>` 选择面板、`/bar clear` 关闭；
- 可选类型：
  - `traffic`——流量监控/10s
  - `production`——产量统计/min
  - `spawn`——实体生成/min
  - `entity`——附近载入的实体
  - `UtilRank`——各玩家所在岛屿 CPU 占用率(‰)
  - `clear`——不显示任何统计条
  - `blockCount`——岛屿方块统计（每分钟刷新；不在界面列表中，需用命令启用）
- 惊变、极限、小游戏等场景会临时接管侧边栏，可在「功能选项」里关闭对应侧边栏。

### 玩家信息面板

`/player <玩家>`（或「玩家菜单」）打开的面板包含：

- 头像悬停档案：加入时间、岛屿数量、勋章积分、金币数量、原版进度、游戏时长、海洋之心数量、佩戴的勋章、幻形等级；
- 功能按钮：岛屿列表、成就勋章、海洋之心、电费账单、幻形、关注/取消关注、传送到其所在岛屿。

### 零碎小知识

- 加入/退出服务器不会播报，死亡消息保持原版样式。
- 服务器会对远处的声音、粒子、方块动画等做节流：人多或实体密集时，远处信息可能不发送到你的客户端——这是正常现象，不是卡顿。
- `/profile view`：查看当前存档档案名（部分玩法使用独立档案）。
