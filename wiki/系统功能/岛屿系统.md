# 岛屿系统

岛屿系统是梦幻之屿的核心：每一位玩家的全部游戏内容——生存、建造、生电、社交——都承载在「岛屿」之上。本页介绍所有岛屿共有的系统机制：世界、出生地、创建、成员、传送牌与常用指令。

各岛屿模式（经典空岛、单方块、海底生存等）的玩法差异不在本页范围，请参阅[岛屿类型](/wiki/空岛类型/总览)。

## 一、游玩流程总览

梦幻之屿**没有主城，没有大厅，也没有冗长的创建流程**。一个典型的游玩路径是：

1. **进入服务器**（地址 `play.molean.com`），首次进服会出现在公共出生岛；
2. **创建自己的第一个岛屿**：按 `G` 打开服务器菜单 → 岛屿菜单 → 创建岛屿，第一个岛免费；
3. **在岛上生存与发展**：你的岛屿拥有独立的主世界、下界、末地三个维度，规则与原版一致；
4. **随时回岛**：输入 `/is` 即可从任何地方回到自己的岛；
5. **邀请成员共同建设**：`/Member Add <玩家>`，经双方确认后对方即获得岛屿权限；
6. **访问他人的岛**：`/visit island #岛屿ID`、传送牌、`/warp` 公共传送点等多种方式；
7. **经营岛屿**：设置名称与图标、修改群系、放置特殊结构、吸引访客点赞留言，甚至下载自己的存档。

## 二、岛屿的世界架构

### 2.1 一岛三世界

**每个岛屿都拥有完全独立的主世界、下界、末地三个维度**，而不是在某个共享世界里划分区域。

- 三个维度相互联通，下界传送门、末地传送门的使用方式与原版一致，因此**双维度刷怪塔、刷沙机等原版生电装置均可使用**。
- 每个岛屿的存档完全独立，互不干扰；岛屿世界在无人访问时不占用服务器资源，有人到来时会自动载入，你几乎察觉不到这个过程。
- 每座岛屿创建时都会分配一个全服唯一的编号（岛屿 ID），从 1 开始递增，它是岛屿最重要的身份标识。

### 2.2 世界边界与坐标

- 岛屿世界**不设置任何额外边界**，可探索范围与原版世界一致，无须担心「岛外禁止前往」的限制。
- 每个岛屿世界都有自己的一套坐标：你的岛心位于本岛世界的 `(256, 60, 256)` 附近，与其他岛屿的坐标互不相关。

### 2.3 世界规则

所有岛屿世界统一适用以下规则：

- 难度：**困难（Hard）**
- 死亡掉落：**开启**（例外情况见「零碎事项」）
- **立即重生**：死亡后不弹重生界面，直接复活
- 重生点无随机散布：始终精确落在出生点上
- 随机刻速度与原版一致：不限制作物生长与红石

## 三、出生地与重生

### 3.1 首次进服

服务器没有大厅。首次进服（尚无任何岛屿）时，系统会自动将你送到**公共出生岛**，你可以直接从这里开始了解服务器，再通过菜单创建自己的岛屿。

### 3.2 岛屿出生点

- 每个岛屿的默认出生点位于**主世界 `(256, 128, 256)`**，即岛心上空；指南针也始终指向该点。
- 岛主可以用 `/home set` 把出生点改到当前所站位置，`/home reset` 恢复默认。
- 从末地返回主世界时，固定落在 `(256, 128, 256)`。

### 3.3 死亡重生

死亡后的重生位置按以下优先级确定（优先级高者生效）：

1. **床 / 重生锚**：你在岛内睡过的床或充能的重生锚；
2. **`/home set` 设置的出生点**；
3. **默认出生点** `(256, 128, 256)`。

如果死亡时所在的岛屿无法重生（例如你是被踢出的访客），会依次尝试：你的第 1 个岛 → #1 兜底岛 → 为你新建一个岛。其中 #1 岛是被玩家称为「监狱」的公共兜底岛——被踢出岛屿、原岛屿不可用等异常情况发生时，你也会被送到 #1。

### 3.4 旁观者状态

当你不处于任何岛屿世界时（异常情况），会处于旁观模式且无法使用旁观传送；回到任一岛屿即恢复生存模式。

## 四、创建岛屿

### 4.1 创建入口

创建岛屿**没有指令入口**，统一通过菜单操作：

> 按 `G` 打开服务器菜单 → 「岛屿菜单」（`/islands`）→「创建岛屿」

### 4.2 创建流程

1. 在创建面板中选择**岛屿类型**（经典空岛、单方块空岛、随机空岛等，各类型玩法见[岛屿类型](/wiki/空岛类型/总览)）；
2. 输入**岛屿名称**（不超过 50 个字符，默认为「我的岛屿」；部分类型还有额外选项）；
3. 确认创建。创建成功后全服会广播「xxx 创建了某类型岛屿 #ID，这是 TA 的第 N 个岛」，你会被自动传送到新岛上。

### 4.3 费用与数量

- **第 1 个岛屿免费**；
- 从第 2 个岛起，每创建一个岛屿消耗 **1 个比特海洋之心**（消耗前有确认弹窗）；
- **岛屿数量没有上限**，只要资源足够可以持续创建。

### 4.4 初始内容

- 岛心结构位于岛屿世界的 `(256, 60, 256)` 附近（不同岛屿类型的初始结构不同）；
- 经典空岛的默认初始物资为：**水桶 ×2、岩浆桶 ×1、苹果 ×64**（部分类型有所不同，如海底生存不提供该物资包）。

## 五、回岛与岛屿间传送

### 5.1 回到自己的岛

| 方式 | 说明 |
|---|---|
| `/is`（别名 `/sb`、`/skyblock`） | 回到你的**第 1 个岛屿** |
| `/spawn` | 传送到**当前所在岛屿**的出生点 |
| `G` 菜单 | 「快速回岛」按钮，等效于 `/is` |

拥有多个岛屿时，用 `/visit player <自己的名字> <序号>` 在岛屿之间切换；序号按岛屿优先级（`/land Priority set` 可调）降序、再按创建时间升序排列。

### 5.2 访问他人的岛

| 命令 | 说明 |
|---|---|
| `/visit island #<ID>` | 按岛屿 ID 访问，如 `/visit island #105` |
| `/visit player <玩家> [序号]` | 访问指定玩家的第 N 个岛；省略序号时打开其岛屿列表 |
| `/visit random` | 随机访问一个岛屿 |
| `/visit randomOnlinePlayer` | 随机访问一位在线玩家所在的岛 |
| `/visit auto <#ID 或 玩家名>` | 自动识别目标 |
| `/land tp <在线玩家>` | 传送到对方**当前所在**的岛屿 |
| `/land tphere <在线玩家>` | 向对方发送邀请提示（不直接传送） |
| `/warp [id]` | 查看/使用公共传送点列表 |

传送的统一规则：

- 落点为目标岛屿的出生点（若岛主用 `/home set` 改过则为新位置）；
- 传送瞬间有 1 秒的物品保护，防止传送途中掉落物品；
- 目标岛屿被锁定、你在其黑名单中、或岛屿被停用时，传送会被拦截。

### 5.3 下界门坐标比例

下界与主世界的坐标换算比例默认为 **8:1**（与原版一致）。岛主可用 `/teleportationscaleset <8|1>` 将其改为 1:1。如果你在下界修的建筑「找不到对应的主世界位置」，先检查本岛的比例设置。

## 六、传送牌

传送牌是最常用的岛屿间传送设施：在木牌上写下目标岛屿 ID 或玩家名，右键即达。作为服务器的特性机制，其制作方法与使用规则已单独成篇，见[传送牌](/wiki/便利功能/传送牌)。

## 七、成员与协作

### 7.1 身份模型

岛屿只有两种正式身份：

- **岛主**：拥有全部管理权限，每岛一人；
- **成员**：获得岛内建造、破坏、交互等全部协作权限。

除此之外的所有玩家均为**访客**。访客默认不能破坏或放置方块（保护机制见 7.5），但岛主可以通过各类开关放宽访客权限。

### 7.2 邀请成员

> `/Member Add <玩家>`

- 仅岛主可用；
- **双向确认**：先向你弹出确认框（附有「乱给权限后果自负」的警示），你确认后再向对方弹出确认框，对方同意后才正式成为成员；
- 加入成功后，对方可用 `/visit island #<ID>` 随时进出你的岛；
- **成员数量没有上限**。

也可以在岛屿设置面板 → 成员管理中操作，支持输入名字或从在线玩家列表中选择。

### 7.3 移除与查看

| 命令 | 说明 |
|---|---|
| `/Member Remove <UUID>` | 移除成员（也可在成员详情面板操作） |
| `/Member List` 或 `/Member View` | 查看成员列表 |

被移除的成员立即失去岛屿权限；若其当时正在岛上，不受影响但不再有建造能力。

### 7.4 转让岛屿

岛屿**没有自助转让的方式**。如确需更换岛主，请联系管理员处理。

### 7.5 岛屿保护与访客控制

- 经典空岛等常规模式默认开启**岛屿保护**：非成员无法破坏、放置、交互、使用桶、伤害实体、拾取或丢掷物品；
- 爆炸与液体（岩浆/水流）有额外的兜底保护，防止波及岛外或恶意破坏；
- 岛主可在岛屿设置面板中调整以下访客相关开关（均为翻转开关，即时生效）：

| 开关 | 命令 | 效果 |
|---|---|---|
| 锁岛 | `/Lock Lock` / `/Lock Unlock` | 锁定后非成员无法进入岛屿 |
| 游客旁观 | `/ToggleSpectatorVisitor` | 访客进入后处于旁观模式 |
| 游客拾取 | `/ToggleAllowItemPickup` | 允许访客拾取物品 |
| 游客丢掷 | `/ToggleAllowItemDrop` | 允许访客丢掷物品 |
| 游客烟花 | `/ToggleAllowFirework` | 允许访客使用烟花 |
| 关闭实体保护 | `/ToggleDisableEntityProtect` | 允许访客与实体交互 |

### 7.6 黑名单

| 命令 | 说明 |
|---|---|
| `/blacklist add <玩家>` | 拉入黑名单（岛主） |
| `/blacklist remove <玩家>` | 移出黑名单 |
| `/blacklist list` | 查看黑名单 |

黑名单中的玩家无法进入你的岛屿，尝试传送时会被拦截并踢出。

### 7.7 子领地

岛屿内还有一套可选的**子领地系统**（`/district`，别名 `/dis`、`/d`），支持在岛内圈地、设置 VISITOR/MEMBER/ADMIN/OWNER 四级区域权限。该功能需管理员为岛屿开启，通常用于多人共建的大型岛屿。

## 八、岛屿自定义与设置

岛主的绝大部分设置都集中在菜单中：**`G` → 岛屿菜单 → 选择岛屿 → 设置**。以下为主要设置项及其命令等价形式：

| 设置项 | 命令 | 说明 |
|---|---|---|
| 岛屿名称 | `/NameSet <名称>` | 不超过 50 字符 |
| 岛屿图标 | `/IconSet` | 消耗副手中的物品作为图标 |
| 出生点 | `/home set` / `/home reset` | 设置/恢复岛屿出生点 |
| 整维度群系 | `/BiomeSet <群系>` | 主世界、下界、末地相互独立设置 |
| 局部群系 | `/RegionBiome add/clear/list` | 用箭矢选区后设置局部群系 |
| 特殊结构 | `/RegionStructure add/clear/list` | 选区内生成前哨站、女巫小屋、海底神殿、下界要塞，全岛同时最多 3 个 |
| 下界门比例 | `/teleportationscaleset <8\|1>` | 见 5.3 |
| 排序优先级 | `/land Priority set/unset` | 影响自己岛屿列表与 `/is` 的选岛顺序 |
| 岛屿环境 | `/StructureSet` | 将整岛环境设为特殊结构（旧机制） |
| 末地门重定向 | `/toggleRelocateEndPortal` | 是否将末地门重定向到本岛末地 |

设置面板中还包含自然刷怪、幻翼、苦力怕爆炸、骷髅骑士陷阱、全岛信标、信标传送、刷石机出矿、Carpet 功能等大量开关，其中防火、防幻翼等部分功能开启时需消耗海洋之心，面板内均有明示。

> 岛屿的各项能力由一系列开关（flag）组成，不同岛屿模式默认开启的能力不同。普通游玩无需关心，想查看本岛开启了哪些能力，可用 `/land info` 或在岛屿面板的 flags 页浏览。

## 九、岛屿社交

| 功能 | 命令 | 说明 |
|---|---|---|
| 点赞 | `/land like [id]`（别名 `/land up`） | 为岛屿点赞 |
| 留言 | `/land comment [id]` | 用副手的署名成书留言，每人每岛限 1 条，重复留言会顶替旧留言 |
| 标签 | `/land tag add/remove <tag>` | 为岛屿打标签，便于检索（删除需成员以上权限） |
| 广告位 | `/land promote` | 消耗 1 个海洋之心购买广告位推广岛屿 |
| 访客记录 | `/land Visitors` | 查看近 3 天的访客 |
| 岛屿详情 | `/land of [id]` | 打开岛屿详情面板 |
| 岛屿检索 | `/land search create/name/pattern/member …` | 按创建者、名称、模式、成员全服检索，结果缓存 2 分钟 |
| 二次筛选 | `/land filter …` | 在上一次检索结果内继续筛选 |

## 十、零碎事项

- **岛屿不能自行删除**。目前没有自助删除/重置的方式，如确需删除请联系管理员；删除是永久性的。
- **存档下载**：输入 `/download` 可获得一份本岛完整存档的下载链接（包含三个维度、统计数据与成就），链接 **1 小时内有效**。
- **死亡掉落**：全服默认死亡掉落。但**访客**（在他人岛上且没有任何权限的玩家）死亡时默认保留物品，有权限者按正常规则掉落；掉入虚空的物品可用 `/recycle mine` 拾回。
- **离开岛屿不掉线**：被踢出、岛屿不可用等异常情况会将你送到 #1 兜底岛。
- **末地返回**：从末地返回主世界时固定落在 `(256, 128, 256)`。
- **岛屿 ID 即身份**：进岛时屏幕标题会显示岛屿名称与「岛屿 #ID 由 xxx 所有」。
- **群系相互独立**：修改主世界群系不会影响下界与末地，反之亦然。
