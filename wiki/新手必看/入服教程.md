# 入服教程

本教程面向从未加入过梦幻之屿的新玩家，带你从零走到登上自己的空岛。

## 一、准备工作

- **正版 Minecraft Java 版账号**：梦幻之屿为正版验证服务器，请确保账号已订阅正版。
- **游戏客户端**：官方启动器，或 HMCL、PCL2 等第三方启动器均可，安装最新版游戏。
- 无需安装任何模组或资源包，原版即可游玩；如需语音等功能，可参考[推荐下载的模组安装使用](/wiki/高手必看/推荐下载的模组安装使用.md)。

## 二、添加服务器

1. 启动客户端并登录正版账号；
2. 进入「多人游戏」→「添加服务器」；
3. 服务器地址填入：`play.molean.com`；
4. 保存后点击「加入服务器」。

梦幻之屿没有主城，也没有创建岛屿的过程——**进入服务器即开始游戏**，你会直接出现在自己的岛上。

## 三、入服后首先了解

- 阅读[岛屿类型](/wiki/空岛类型/总览)：了解你的岛屿属于哪种模式（经典 / 单方块 / 海底 / 困难等），以及岛屿可用的特性；
- 使用指令 `/quest open` 打开任务面板，通过 Lv1–Lv4 空岛挑战循序渐进地熟悉服务器；
- 物资与机制相关问题，可查阅[部分物资获取](/wiki/高手必看/部分物资获取.md)与[常见问题](/wiki/常见问题.md)。

## 四、遇到卡点？找玩家求助

入服过程中遇到任何困难——连不上服务器、不知道开局做什么、找不到某种物资——都可以在 QQ 群里直接提问，群里总有乐于解答的玩家（二维码见[加入我们](/join-us)页面）。群内也是获取最新服务器动态与活动通知的主要渠道。
