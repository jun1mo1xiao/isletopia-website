# 群内小游戏 · 挖矿

「一日矿洞」是一个**全服共享、一日一次**的矿洞探险游戏：每天 08:00 之后可以下矿一次，从洞口 (0,0) 往下探索一座所有玩家共用的矿洞。移动、开采、战斗都围绕**饱食度**展开，用完就会被困在洞里等人来救。矿洞里埋着矿脉、宝箱、幸运方块与怪物，矿脉周围有怪物看守；深处有下界传送门通往岩浆海与下界要塞，赛季主线则要从 8 条线索里找到要塞、献祭末影之眼打开末地门、屠龙拿到藏宝图，最后挖出**矿洞之心**。装备、仓库与称号跨赛季永不丢失——换赛季只是换一座新矿洞。

这是一款**网页游戏**：在 QQ 群里发 `/挖矿` 拿到入口链接，授权登录后，下矿、移动、开采、战斗、商店、升级、附魔全在浏览器里点。群里保留的只有三样——`/挖矿` 看状态摘要与入口、`/挖矿 登录 <码>` 确认网页登录、以及线索发现 / 屠龙成功这类大事件的系统播报。

## 一、快速开始

1. **前置条件**：完成 QQ 绑定（见[QQ 机器人绑定系统](../QQ群功能/QQ机器人绑定.md)）。群里的 `/挖矿` 与 `/挖矿 登录` 都按绑定的游戏账号计。
2. **拿入口**：在 QQ 群里发一次 `/挖矿`，机器人回一份状态摘要，末尾带「打开网页版矿洞」的链接。
3. **打开网页**：点链接进入 `mc.molean.com/web/mine/`。**建议在浏览器中打开**——在 QQ / TIM / 微信内置浏览器里打开时，页面顶部会提示「点右上角 ··· → 在浏览器打开」，并提供一键复制链接。
4. **生成授权码**：在登录页点「生成授权码」，得到一组 **6 位数字**，有效期 **5 分钟**。点「一键复制指令」，或手动长按复制。
5. **群里确认**：把 `/挖矿 登录 <授权码>` 发到 QQ 群。网页每 2 秒自动查询一次，机器人确认成功即自动进入矿洞。
6. **开始挖**：点「下矿」，从洞口出发。之后所有操作都在网页里完成。

> 授权码只是首次登录的凭证，网页不会要你的账号密码。过期或不小心关掉页面，回到登录页重新生成一个即可；同一 IP 每 10 分钟最多生成 5 个，短时间内连续失败 5 次要等 10 分钟再试。

## 二、网页界面导览

### 矿洞主视图

主视图用 Minecraft 方块贴图把眼前这一片矿洞画出来（你居中，视野跟着屏幕走：宽屏多铺几列、屏幕越大看得越远）：

- **只有走过或被火把照亮的格子才显形**：这些格子显示真实内容（石头 / 深板岩 / 各种矿石 / 怪物 / 宝箱 / 岩浆……）；勘探熟练度还低时只看得出粗分类幽影——矿脉（灰白矿脉）、怪物（暗紫剪影）、宝箱（压暗的箱子），升到 II 档起逐步显示真身；
- 黑着的是没探明（跟视距无关），**光圈里但没探明的格子只画成可疑岩石（圆石）**：矿、怪物、陷阱都不会提前显形，走过去或插火把才知道是什么；被火把照亮但还没走过的格子加一圈金色描边；
- 你自己站的位置是绿框，正在战斗的格子红框闪烁。

地面分三种：**泥土**是可以随便走的空地；**圆石**（可疑岩石）是「这里有东西但还没探明」，点它开采揭晓；**基岩**是矿洞边界。光圈照到的地方都会告诉你真实状态——空地就是泥土、有东西就是圆石或真身；光圈之外的黑暗里看不出内容，走过去才知道。泥土上绝不会有东西——如果看着像矿脉的格子挖不出矿，那多半是蠹鱼伪装的（IV 档熟练度才能识破），走过去就会遭遇战斗。

**全部靠点击操作**：

| 点哪里 | 发生什么 |
|---|---|
| 点相邻格 | 走一步（移动免费） |
| 点远处的格子 | 自动沿最短路线寻路走过去，途中只回一次结果 |
| 点矿石 / 宝箱 / 幸运方块 / 末地水晶 / 藏宝格 | 系统先把你带到旁边，再执行开采 |
| 点未知格或怪物格 | 走过去试探（未知格等于开盲盒） |
| 点自己脚下 | 旁白提示，用来确认当前位置与状态 |

还没探索、基岩边界、有东西挡路（矿脉/宝箱/怪物）的格子点不动，得先开采或清怪把路打开。想回家不用找路：矿洞视图右上角常驻「返程」按钮（-1 饱食度），旁边还有「攻击」与战斗中的「逃跑」。键盘也能操作：`WASD` 走一格，`R` 返程；战斗中不能移动，只能攻击或逃跑。横屏宽屏下侧栏常驻在右侧，竖屏 / 窄屏会收成底部抽屉，点摘要条或上滑展开。

## 三、备战：下矿前的准备

下矿机会每天只有一次，物资与装备都得**在洞外准备好**。网页版的备战分成「装备工坊 / 购买 / 出售 / 合成 / 仓库 ⇄ 携带」几个页签，一屏只做一件事。购买、出售、合成、仓库 ⇄ 携带栏互相转移、装备升级，统统只能在洞外操作；**进矿后只能用随身带下去的物资**——商店、仓库、升级在矿中都用不了，被困时也一样。所以下矿前先做三件事：

1. **买**：在「商店」面板买消耗品。买到的道具先进**携带栏**（占负重，负重上限就是背包容量），下矿时自动整体带下去。
2. **装**：在「背包」面板把仓库里的道具「携带」进携带栏，买多了的再「卸下」回仓库——只有携带栏里的东西会跟着你下矿。
3. **升**：在「装备」面板升级矿镐 / 护具 / 背包、切换穿戴材质、消耗附魔卷轴附魔。升级扣的是**仓库**里的材料与金币，先把材料备齐再升。

矿袋是本趟探险的临时口袋：矿中采到的矿石、怪物资源与宝箱物资先装进矿袋，**等返程后才全部入库**。装备、仓库与称号跨赛季永不丢失；升上去的材质还能在装备面板主动穿低级来省负重。

**体力见底提醒**：饱食度掉到 **1 点**时会弹窗问要不要立即返程（战斗中会等打完再问）——再掉 1 点就会被困在矿洞里等人来救。

**看见队友**：地图上会显示同图其他玩家的名字条——<span style="color:#7ee787">绿色</span>是在下矿的人，<span style="color:#ff7b72">红色</span>是困在原地等人救的人；走到同一格就能点「救援」把对方拉回地面。

**最近结算**：一回合里可能同时中毒、挨高温、遇增援、捡到东西，弹窗只飞得下前几条——状态页签底部的「最近结算」列着完整的这一回合。

## 四、饱食度与每日循环

饱食度是你唯一的行动资源：**每次下矿自带 20 点，上限 20**。移动不花饱食度，开采、赶路结算与各种环境代价才花。

| 动作 | 消耗 |
|---|---|
| 移动（含探索新区域与天然洞穴） | 免费 |
| 攻击 / 逃跑 / 插火把 / 使用道具 / 丢弃 / 交易 | 免费 |
| 返程 | -1 |
| 用末影珍珠紧急返程 | -1 |
| 开采普通岩层 | -1 |
| 开采深板岩（y≥29） | -2（先布置 TNT 可降到 -1） |
| 开采末地水晶 | -2 |
| 挖幸运方块 / 挖出矿洞之心 | -1 |
| 踏入深坑 / 流沙 | -1 |
| 站在毒气上（每个动作） | -1（牛奶本次免疫） |
| 下界高温（每个动作） | -1（火焰保护附魔免） |
| 中毒（洞穴蜘蛛，每回合） | -1（牛奶解） |
| 被监守者震回 | -2（羊毛垫或潜行附魔可安全通过） |
| 救援同格玩家 | -1 |

- **食物**：面包 +1（30 金币）、牛排 +2（80 金币）、金苹果 +4 并挡下一次伤害（500 金币）。被尸壳咬到会「饥饿」，本次下矿食物回复减半。饱食度满时不能再吃。
- **负重**：每个物品都占负重（矿石 1~4 不等，消耗品见商店表），上限 = 背包容量。**超重了也能继续挖**，只是超重时不能返程（末影珍珠逃生同样不行）——用「丢弃」把矿袋里的东西扔掉减重，再走。
- **每日一次**：每天 **08:00** 重置下矿机会，一天只能下一次——即使中途被困、放弃或提前返程，也要等第二天。被困状态跨日保留。

## 五、矿洞、深度与地形

- 矿洞**全服共享**：别人探索过的格子，你走上去免费，探索榜上也会记名。
- 主世界 x∈[-120, 120]，y∈[0, 64]，基岩带 61~64 走不过去。深度分带：

| 深度 | 分带 | 主要产出 |
|---|---|---|
| y0 | 洞口 | 起点，无内容 |
| y1–12 | 浅层 | 煤、铜 |
| y13–28 | 中层 | 铁、青金石 |
| y29–48 | 深层 | 金、红石、钻石（深板岩开采 -2 饱食度） |
| y49–60 | 深渊 | 钻石富集、末影人、远古城市 |
| y61–64 | 基岩 | 不可通行 |

- 主世界散布着**废弃矿井（含刷怪笼房）、地下湖、紫水晶洞、远古城市（监守者岗哨 + 顶级宝箱）、要塞入口与下界传送门**等结构。
- 各深度带还随机分布**天然洞穴**（覆盖率约 5%~8%，越深略多）：洞穴格是天然空腔，**踏入免费**，里面照常能挖到矿物、开宝箱，但怪物密度比普通岩层高五成。
- **火把插在刷怪笼上可以封印它**，否则第二天 08:00 怪物会重新出现；已经打掉的普通怪物不会复活。

矿石与怪物资源不会自动变现：开采后先装进矿袋，返程时**原样存入仓库**，之后在商店面板「出售」它们换金币。

怪物掉落的资源道具同样进矿袋、同样可以出售：腐肉 8、糖 6、箭 8、线 12、骨头 15、黏液球 18、火药 25、荧石粉 30、绿宝石 33、岩浆膏 40、恶魂之泪 120（均负重 1）。

- **镐子决定能挖什么**：挖不动的矿会直接告诉你还差哪一档镐子。
- **守卫锁定**：矿脉 / 宝箱周围 **8 格**内有活怪时不能开采，先把怪清掉；战斗中的格子会锁定 5 分钟，期间别人进不来。
- **蠹鱼伪装**：蠹鱼会伪装成矿脉，一镐下去才现形；情报到 IV 档可以提前识破。
- **主线道具**：末影人掉落的**末影珍珠**、烈焰人掉落的**烈焰棒**不占矿袋、不能出售、跨赛季保留，只用于赛季主线的献祭。

## 七、危险地形与对策

危险格在地图上按类型显示；除了绕开，多数都有正面解法：

| 危险 | 后果 | 对策 |
|---|---|---|
| 岩浆 | 踏入烧掉矿袋里随机 1 件物资 | 用「水桶」扑灭，此后对全服永久安全 |
| 岩浆海（下界） | 一次烧掉 2~3 件矿袋物资 | 用「水桶」扑灭，或绕开 |
| 流沙 | 踏入 -1 饱食度 | 用「水桶」凝固，此后永久安全 |
| 深坑 | 踏入 -1 饱食度 | 摔落保护附魔可免；或绕开 |
| 毒气 | 站在上面每个动作 -1 饱食度 | 喝「牛奶」解毒，本次下矿免疫毒气 |
| 下界高温 | 下界里每个动作 -1 饱食度 | 火焰保护附魔免疫 |
| 中毒（洞穴蜘蛛） | 每个回合 -1 饱食度 | 喝「牛奶」解毒 |
| 监守者岗哨 | 被震回原地并 -2 饱食度 | 带「羊毛垫」自动铺开安全通过；潜行附魔无需羊毛垫 |

水桶的效果**全服共享且永久有效**：你扑灭的那一格岩浆，之后所有玩家都能安全走过。

## 八、怪物与战斗

点怪物格或在旁边点「攻击」即进入战斗：**攻击不耗饱食度**，但每次失手怪物都可能反击。战斗面板会公示本回合的胜率与击穿率，方便你决定打还是跑。低情报熟练度下怪物只显示成剪影，点它就是走过去开战；矿脉或宝箱被怪看守时挖不动，系统会直接点出**看守的是谁、站在哪一格**，先去清掉它再回来挖。

- **战力** = 矿镐材质基础 + 每级 +1：木 12 / 石 20 / 铁 35 / 钻 55 / 合金 80（幸运方块「时来运转」+10）。
- **护甲值** = 护具材质基础 + 每级 +1 + 附魔：皮 4 / 锁链 7 / 铁 10 / 钻 18 / 合金 25（坚固 +5，其余附魔 +3）；未佩戴护具为 0。
- **胜率** = 50% + 4% × (战力 − 怪物血量)，夹在 5%~95%。
- **击穿率** = 40% + 3% × (怪物攻击 − 护甲值)，夹在 5%~95%；烈焰人的火球被火焰保护额外降低 15%。
- 打赢后怪物**永久清除**，守卫锁定随之解除，并掉落资源；被击穿则 -1 饱食度。
- **逃跑**撤到相邻已探索格（不耗饱食度）：骷髅会追一箭（必中），其他怪物 35% 追击。逃跑的那一格会被探明——下次可以看清了再打。

## 十一、被困与救援

- 饱食度归零会被**冻结在原地**：矿袋与带入物资锁在那一格，群里会播报 🆘 喊人来救。
- **被人救**：任意玩家在自己的下矿里走到你那一格，点「救援同格玩家」——救援者 -1 饱食度，你 +1 饱食度解脱，**矿袋物资全部保住**。
- **自救**：用「末影珍珠」（800 金币）立即返程，矿袋物资照常全部入仓库；点「放弃」当场解脱，但矿袋与带入物资全部清空。
- **再生图腾**（远古城市顶级宝箱）在濒死瞬间自动触发一次：饱食度直接回到 3 点，继续这一趟。
- 被困状态**跨日保留**：当天被救出来还能继续玩；没人救，就得等第二天。
- 被困时矿袋冻结，但**随身携带栏里的道具仍然能用**（比如珍珠、食物），矿袋与携带栏的东西也**可以丢弃**（超重时靠它减重：珍珠逃生与返程都要求不超重）。不过洞外的商店、仓库与升级这时都够不着，补给只能靠下矿前备好的那一份。

## 十二、三界与传送

矿洞不止主世界：**下界、要塞、末地**各自是一张独立子图，靠传送格连接。

| 地图 | 范围 | 内容 |
|---|---|---|
| 主世界 | x -120~120，y 0~60 | 全部矿物、怪物、宝箱、结构与赛季线索 |
| 下界 | x -80~80，y 0~32 | 石英 / 金 / 远古残骸、岩浆海、猪灵、烈焰人、下界要塞 |
| 要塞 | 40 × 20 迷宫 | 走廊与房间、图书馆（第 8 条线索）、末地门 |
| 末地 | 41 × 41 | 主岛（末影龙 + 5 颗水晶 + 末影人）；下方三座外岛隔着虚空，去不了 |

- **下界传送门**（主世界 2 座，与下界按序号双向配对）：踩上去即传送。下界高温每个动作 -1 饱食度，火焰保护附魔可免。
- **要塞入口**藏在主世界深层，进去是走廊-房间迷宫；图书馆里有第 8 条线索，出口在地图右下角，末地门在传送门房间。
- **末地门**：集齐 **12 颗末影之眼**后踏上门格进入末地；主岛中央的末影龙就是本赛季的 Boss，外围还有 5 颗末地水晶。

## 十三、赛季主线

赛季是全服一起推的一条主线，右侧「赛季」面板随时能看进度：

**第一幕 · 拓荒**：主世界深部散布着 7 条线索，要塞图书馆里还有 1 条，共 **8 条**。发现线索会向全服播报方位提示，线索越多、要塞位置收得越窄。

**第二幕 · 寻钥**：在要塞传送门房间的「状态」面板点献祭，每献祭一颗消耗 **1 末影珍珠 + 1 烈焰棒**。集齐 **12 颗**末地门开启；6/12 与 12/12 都会播报。

**第三幕 · 决战**：进入末地，先砸 **5 颗末地水晶**（每颗 -2 饱食度）降低难度，再攻击末影龙：

- 屠龙率 = 8% + 0.5% × (战力 − 60)，夹在 2%~60%；**每存活 1 颗水晶再 ×0.85**；
- 攻击不耗饱食度、不限次数；失手有 30% 被龙息灼烧 -2 饱食度（火焰保护减为 -1，金苹果护盾可挡）；
- 屠龙成功的**最后一击者**获得矿洞之心的藏宝图，状态栏会显示宝藏的方位与距离。

**第四幕 · 寻宝**：持图者去藏宝格点「开采」，挖出**矿洞之心**：+50000 金币、称号「屠龙者」，本赛季目标达成。

**刷新**：龙死次日 08:00 世界刷新——新的矿洞、下界与末地，新的线索与宝藏全部重置，开启新赛季；装备、图鉴、称号与仓库物资**全部保留**。

线索发现、钥匙进度、水晶击碎、有人被困 / 获救、屠龙成功、之心出土与新赛季开启，都会在群里播报。

## 十四、常见问题

**登录态能保持多久？**
授权成功后网页会记住你的身份，登录态**30 天**有效，期间只要登录过就自动续期，不用反复确认授权码。

**换设备或清理浏览器数据后怎么办？**
登录态存在本机浏览器里，换设备（或清了缓存、换了浏览器）需要在网页上重新生成授权码，再发一次 `/挖矿 登录 <码>`。同一游戏账号可以同时在多台设备登录。

**为什么 QQ 里点开链接会提示换浏览器？**
QQ / TIM / 微信内置浏览器对页面的支持有限，页面会提示「在浏览器中打开」并提供复制链接。换个浏览器打开体验更完整。

**每天能下矿几次？**
一次。每天 **08:00** 重置；当天没及时玩，那天就错过了。

**我卡在矿洞里 / 饱食度耗尽动不了怎么办？**
被困时矿袋冻结在原地，等群友走到你那一格点「救援」；也可以自己用末影珍珠逃生，或者点「放弃」（会清空矿袋与带入物资）。被困状态跨日保留。

**矿石什么时候变成金币？**
矿石不会在返程时自动变成金币。返程（或用末影珍珠逃生）后，矿袋物资**原样存入仓库**，返程结算窗会列出本趟入库清单。想要金币，就在洞外的商店面板把仓库里的矿石与怪物资源「出售」掉；材料留着升级装备也可以。

**会不会因为掉线丢进度？**
不会。每次点击都会立即结算并落库，网断了重进页面接着就是；战斗格有 5 分钟占用锁，锁过期自动释放，那一格留给别人。
