# 群内小游戏 · 农场

农场是一个「真实时间制」的种植玩法：**8 块地**，花金币播种后按现实时间生长（离线也在长），成熟后一键收获。
全服共享**季节与天气**，作物分**品质与突变**，产物先进**数字仓库**，可以随时直售或卖给当天的**市场窗口**；
还能偷别人的菜、养**看菜狗**防偷、发现并**分享当天的幸运作物**。

> 本文数值以游戏内显示为准；赛季锚点、市场价格等参数来自服务端配置，会随版本调整。
>
> 每条指令执行后都会直接告诉你下一步：正文里出现的指令点一下即可填入，消息底部的按钮点一下就能执行，不需要手动输入。

## 一、游玩流程总览

1. **前置条件**：完成 QQ 绑定（见[QQ 机器人绑定系统](../QQ群功能/QQ机器人绑定.md)）。指令**仅在 QQ 群可用**（别名：`种地`、`farm`、`菜园`）。
2. **看天吃饭**：`/农场 天气` 看今日天气与明日预报，`/农场 季节` 会直接列出**当季推荐作物**——名字点一下就能播种。
3. **选种**：`/农场 商店` 按解锁等级挑种子，作物名点一下就是「种这个作物」；想看全表用 `/农场 商店 全部`，也可用 `/农场 商店 5` 直接跳到 5 级新解锁的一档。
4. **播种**：`/农场 种植 小麦 8`——只扣金币、不需要种子物品；数量省略或填 0 表示种满所有空地。
5. **维护（可选）**：`/农场 浇水` 免费补满水分；`/农场 施肥` 使用**肥料道具**——**嫩芽肥/茂叶肥/拔节肥**（+10%/20%/30% 生长速度，持续 24 小时）、**早熟剂/速熟剂/即熟剂**（直接把当前周期提前 1/2/3 小时）与**净田肥**（24 小时内不再长虫长草，已经长出来的要自己除），都是**农场级效果、一次作用于全部地块**。肥料**只能靠玩法获取**（随机事件、除虫除草、投喂狗、图鉴首收、幸运发现、图鉴每集齐 15 种作物送 1 个净田肥），**不能买也不能卖**，每天最多用 3 个；`/农场 仓库` 的道具区能看到持有量并点击使用。`/农场 除虫`、`/农场 除草` 免费清理——除虫每块地给 1 个钓鱼鱼饵，除草给 1-3 颗当季作物的改良种（作物周期越长、土地档位越高，翻出的越多）；另外新道具**净田肥**能让你 24 小时内不再长虫长草。
6. **收获**：`/农场 收获` 一键收全部成熟作物。原生作物的一部分产物通过**游戏内邮箱**发放（游戏内 `/assist mailbox` 领取），另一部分进入**农场仓库**；虚拟作物只进仓库。
7. **变现**：`/农场 仓库` 看库存，`/农场 出售` 随时直售，`/农场 清仓` 一次卖光所有可卖的（按直售价），`/农场 出售市场`（不填商品即可全部卖掉）卖给当天市场窗口拿更高价。
8. **社交**：`/农场 偷菜` 偷别人的菜，`/农场 领狗` 养看菜狗防偷，`/农场 幸运` 与 `/农场 分享幸运` 参与当天的幸运发现。

## 二、基础规则

| 项目 | 规则 |
|---|---|
| 地块 | 固定 **8 块**，无需开垦；每块地可升级两次土地档位 |
| 生长 | 按真实时间计时，离线照常生长；作物成熟时会在群里提醒你 |
| 季节 | 每 **7 天**换一季、**28 天**一轮，全服统一 |
| 天气 | 每天全服一份（晴/雨/阴/干旱/霜冻大风），可提前看明日预报 |
| 每日偷菜 | 基础 **4 次**；事件/库存的额外次数每天最多再用 **2 次**（库存永久保留、不清零） |
| 肥料道具 | 嫩芽肥/茂叶肥/拔节肥（+10%/20%/30% 速度，24 小时）、早熟剂/速熟剂/即熟剂（提前 1/2/3 小时）；**只能靠玩法获取**，每天最多用 **3 个** |
| 农场等级 | 靠累计经验提升、**不会消耗**；等级决定可种作物与土地升级资格 |
| 土地 | 普通土地 → 红土地 → 黑土地，每块地最多升 2 次，全农场最多 **16 次**升级 |
| 货币 | 全部走金币；种植、买狗、种子合成、土地升级会扣费，出售与事件收入进金币（肥料道具不花金币） |
| 结算 | 涉及金币与邮件的操作由服务端事务结算，「处理中」会自动重试，正常情况不会丢奖励 |

## 三、种植与收获

### 种植

- 作物可以用中文名、别名或 cropId 指定，支持部分匹配：`/农场 种植 小麦`、`/农场 种植 wheat_seeds` 都可以。
- 费用 = 种子单价 × 数量，从金币余额扣除；空地不足时只种能种下的部分。
- **品质**：`/农场 种植 <作物> <数量> <品质>`，品质为 `普通` / `改良` / `优良`。品质更高更容易出高品质产物，优良种子还可能回收改良种子。
- **解锁等级**：农场等级不够时不能种该作物（见[作物总表](#十二-作物总表)）。
- **适季**：标记「仅适季可种」的作物只能在它的适季播种；其余作物全年可种；**适季 +16% 生长速度，非适季 -8%**。

### 生长阶段与过熟

- 每块地有四个阶段：**发芽 → 生长 → 开花**（不同作物显示为灌浆 / 包心 / 结果 / 成材等）**→ 成熟**。
- **过熟**：成熟后不收，前 **24 小时**没有损失；之后每 **12 小时**少收 **3%**，最多少收 **30%**。**不会枯死、不会掉品质。**

### 水分与维护

| 操作 | 效果 | 消耗 |
|---|---|---|
| `/农场 浇水 [地块\|全部]` | 把目标地块水分补满 | 免费，同一玩家 **4 小时冷却** |
| `/农场 施肥 <肥料道具>` | **农场级**效果，一次作用于全部地块：嫩芽肥/茂叶肥/拔节肥 = 24 小时内 +10%/20%/30% 生长速度；早熟剂/速熟剂/即熟剂 = 直接把当前周期提前 1/2/3 小时；净田肥 = 24 小时内不再长虫长草（已长出的要自己除） | 消耗 1 个道具，**不花金币**；每天最多用 3 个 |
| `/农场 除虫 [地块\|全部]` | 清除虫害；每块地给 1 个钓鱼鱼饵（**作物周期越长越容易出稀有饵**） | 免费、不限量 |
| `/农场 除草 [地块\|全部]` | 清除杂草；翻出 **1-3 颗**当季作物的改良种（周期越长越可能翻出多颗，红土/黑土再往上偏） | 免费、不限量 |

- 水分**每小时**变化：晴天 −4、阴天 −2、霜冻大风 −3、干旱 −6，**雨天 +6 回补**（所以雨天常常是满的）；红土/黑土分别再少 12%/25%。
- 水分 ≥60 生长最快，30–59 有 85% 速度，1–29 有 70%，**0 也还有 60% 速度、永远不会枯死**；收获时的水分还影响品质。
- 土地、种子、季节、肥料、水分、天气、虫草的加成**全部叠加、不再截断**：顶配（黑土 + 优良种 + 适季 + 拔节肥 + 雨/水满）会明显更快，反之不维护也会明显更慢。
- 虫害与杂草**按天生长**：每天有固定配额（春 28 / 夏 44 / 秋 32 / 冬 24 次，**虫草合计、全农场共享**，每天早上 8 点重置），在地块里随时可能长出来——单块地平均 **2 小时**长一次（服务器每分钟判定一次），长出来后 **1 小时内不会再长第二棵**。
- 好种好地真的更省心：**抗虫抗草的作物 + 优良种 + 红土/黑土**会直接减少每天的配额（最多能压到三分之一），而不只是换个地块长。每天的配额在**早上 8 点重置时定下**，当天不再随换作物/升土地变化（所以同一天的「今日虫草 X/Y」是稳定的）。
- **长出来就要及时清**：按「作物周期的 20%」为一拍（30 分钟作物 6 分钟一拍、24 小时作物 4.8 小时一拍），每拍未清，虫 **少收 2%**（单周期最多 10%）、草 **少收 1%**（最多 5%），同时各扣 1 点品质分；草在场期间还会让生长慢 10%。**清掉的那一刻起就不再累计**——短周期作物要盯紧，长周期作物一天不管也只是十几趴。

### 品质与突变

- 收获时判定 **普通 / 改良 / 优良**：品质越高，仓库里的**售价越高**（数量由土地档位决定）；另外高品质的种子长得更快、更抗虫；收获时出**优良品质**必定翻出 2-4 颗同作物的改良种（周期越长给得越多）。
- 收获时小概率产出**突变品**（同一商品、售价更高）；`/农场 诱导剂 [地块\|全部]` 消耗 1 个诱变剂，把该地块本周期的突变率提高到 **25%**。

## 四、土地档位与农场等级

- 固定 **8 块地**；每块地可在 **普通土地 → 红土地 → 黑土地** 之间升级两次，全农场最多 **16 次**。
- 升级只花金币、需要农场等级达标，且**按 1 号地到 8 号地顺序逐块解锁**（黑土地要求该地块当前是红土地；已经升黑的地不会挡住后面地块升红土）。
- 档位越高：进入仓库的份数越多（普通 1.00× / 红土 1.35× / 黑土 1.80×）、品质上限越高、维护更省心、生长略快；但**原生作物发到邮箱的那部分数量固定不变**。
- 指令：`/农场 土地` 查看档位与下一个可解锁槽位（还差几级、需要多少金币）；`/农场 升级 <地块>` 升级指定地块。
- 农场等级只靠经验提升，上限 **30 级**；经验来自收获、维护、幸运发现、图鉴等，**完全按作物生长时长给**（1.5 点/小时），品质（改良 ×1.05 / 优良 ×1.15）与维护达成（×1.10）是乘数，没有每日上限——种得越久经验越多，靠高频刷短周期作物拿不到额外经验。

## 五、季节与天气

- 全服统一季节：每 7 天换一季、28 天一轮（春 → 夏 → 秋 → 冬）；**适季生长 +16%、非适季 -8%**，所以按季节换作物收益差别很大。
- 每天全服一份天气：晴 / 雨 / 阴 / 干旱 / 霜冻大风，影响水分、生长速度、虫草概率与品质评分；明日天气可以提前看到。
- 指令：`/农场 季节` 除了季节与剩余天数，还会按你的等级列出当季推荐作物，名字点一下就能种；`/农场 天气` 看今日天气与明日预报。

## 六、仓库、出售与市场

- `/农场 仓库`：查看数字仓库，按商品 / 品质 / 变体分桶（分桶有上限，满了提示清理）。仓库商品**不占背包**。
- `/农场 出售 <产品> [数量] [品质] [变体]`：随时可卖的普通直售，按分桶计价，没有数量与额度限制（也不参与市场限量）。
- `/农场 清仓`：一次性把仓库里**所有可卖的分桶**按直售价卖光——先给预览（分桶数、件数、预计金币）与确认按钮，确认后才执行；金币树产物不受影响，仍需单独兑换（每周有次数与金额上限）。想卖更高价就先看 `/农场 市场`。
- `/农场 出售市场 [产品] [数量] [品质] [变体]`：卖给当天的市场收货窗口，价格比直售高得多；**不填产品就是把今天市场收的全部商品一次卖掉**（每个商品吃满当日额度、紧俏优先 ×10）：
  - 每天有 **8–12 个普通收购商品**，按仓库单价 **3 倍**收；
  - **1 个紧俏物资**按仓库单价 **10 倍**收；
  - 普通池**每人每商品每天 30 份**，紧俏**全服每天 300 份、每人每天 100 份**（先到先得）；两者都**不限金币总额**（超出份额的部分留在仓库，可以直售或等明天）。每天的普通池里**至少 3 个低级商品、至少 2 个高级（T4/T5）商品**，新手与老玩家都有出口。
  - 同一个商品可能既是当天的紧俏物资、又在普通收购池里：卖给市场时先按 **10 倍** 收满紧俏额度，紧俏额度用完（全服抢完或你自己的 100 份用完）后，同款商品**继续按普通池 3 倍**收。两边的份额各算各的，不会出现「紧俏卖完了就整单卖不掉」的情况；当天的紧俏商品在 `/农场 市场` 里会标出这一点。
- 市场只收当天收购范围内的商品；不在范围内的商品卖不了，会留在仓库里，可以走直售。
- 指令：`/农场 市场` 查看今天收什么与当日单价，点商品名直接卖。

## 七、幸运：发现与分享

- 每天有 **6 种**保密幸运作物（从当季可种作物中抽取）。收获命中尚未确认的幸运作物时，有机会**发现**它。
- 发现后可以 `/农场 分享幸运 <作物>` 分享到群里，群友可以**跟种**并获得额外收益（当天收获可得仓库份数 +10%，每玩家每日最多 3 次）；分享成功时群里的提示会 @你并写上你的游戏 ID。
- 分享只认**当天已确认**的作物：没确认的作物（哪怕它真的是幸运）和不在名单里的作物，提示一模一样——猜不出名单。
- `/农场 幸运` 只显示你已经确认的进度，没人发现的作物不会公开。

## 八、偷菜与看菜狗

- `/农场 偷菜 [玩家]`：每天基础 **4 次**，需要你的余额 ≥ **1000 金币**；省略玩家名则从关注列表里自动挑成熟地块最多的下手。
  - 偷**一年生**作物：收走该地块全部成熟产物，地块清空；
  - 偷**多年生**植株：只取当期产物，植株与寿命保留。
- 被偷的主人会收到记录与**补偿**（按产物价值折算，有单地块与每日上限）；`/农场 被偷记录`、`/农场 偷菜记录` 可查最近 20 条。
- `/农场 关注 <玩家>`（上限 4 人）是自动偷菜的目标池，也方便 `/农场 查看 <玩家>` 盯别人菜地的成熟时间。

### 看菜狗

| 项目 | 数值 |
|---|---|
| 首只 | **免费**（`/农场 领狗`） |
| 后续价格 | 1000 金币/只 |
| 有效期 | 7 天 |
| 上限 | 8 只 |
| 触发概率 | 每只有效狗独立 **12.5%**（投喂凶猛狗粮后 **18.75%**） |
| 被咬惩罚 | 小偷损失 **500 金币/只触发狗**（不超过其余额），金币**转给狗主人**；投喂金币狗粮后为 **750 金币** |

续费逻辑：有狗将在 3 天内过期时，购买会优先续上最早过期的那只；8 只都在效期内且都不临近过期时才拒绝购买。
指令：`/农场 领狗`、`/农场 买狗 [数量]`、`/农场 狗狗信息`、`/农场 狗记录`。

**狗粮（投喂）**：收获作物时可能从随机事件里掉出狗粮，用 `/农场 投喂 <凶猛|金币|普通>` 喂给看菜狗。三种狗粮等概率掉落：

| 种类 | 效果 | 时长 |
|---|---|---|
| 凶猛狗粮 | 咬人概率 **+50%**（每只 12.5% → **18.75%**） | 3 天 |
| 金币狗粮 | 咬人掉的金币 **+50%**（500 → **750 金币/只**） | 3 天 |
| 普通狗粮 | 现有每只看菜狗 **续期 3 天**（不复活已过期的狗） | 一次性 |

- 凶猛/金币狗粮是**农场级效果**：对全部看菜狗生效，**之后新买的狗同样生效**；重复投喂会在剩余时间上叠加，不会浪费。
- 库存、当前效果与剩余天数可以在 `/农场 狗狗信息` 里查看。

## 附：人机验证（反脚本）

为遏制约本挂机，农场与钓鱼指令会**随机抽验人机**：抽中时会在指令回复之后收到一条「人机验证」提示，要求你在 **10 分钟内**发送 `/验证 <描述>`，用规定字数（20~60 字之间随机）描述一个指定物品——获取方式、用途、特点、外观等都可以写。

- 抽验不影响指令本身，指令照常执行；字数不够会提示你补写后重发。
- 完成验证按提交字数发放金币奖励（每字 10 金币，提交后立即到账）。
- 提交成功后 **1 小时内**不会再被抽验；正常游玩基本无感。
- **超时 10 分钟未提交**：1 小时内不能使用农场/钓鱼指令，到期自动解除；如有异议请联系管理员。
- 验证记录（描述内容、用时、打字速度）会留存并由管理员抽查复核：回答被认可会**降低**你被抽验的概率（最低 1%，不会完全不抽）；回答与题目不符会被**拒绝**，收回本次奖励金币并在群里通知你——这不代表被判定为脚本，被判定为脚本的账号会直接封禁。
