# 群内小游戏 · 每日签到（每日抽奖）

每日签到是最轻量的群内小游戏：每天抽一次 **0–999 的幸运数字**，数字既决定你的金币奖励，也决定你能不能抽到服务器唯一高级货币——**海洋之心**。连续签到不中断可提升中奖概率，并给金币奖励叠加加成。

## 一、游玩流程总览

1. **前置条件**：完成 QQ 绑定（见[QQ 机器人绑定系统](../QQ群功能/QQ机器人绑定.md)）。签到指令仅在 **QQ 群**可用。
2. **抽奖**：在群里发送 `/签到`（别名：`今日抽奖`、`每日抽奖`、`抽奖`，也可不带 `/`）。每天一次，按绑定的游戏账号计。
3. **出奖**：系统抽取一个 0–999 的幸运数字——数字够小（连签 7 天后放宽）抽中**不可交易的海洋之心 ×1**，否则获得「幸运数字 + 连签加成」的**金币**，直接入账。
4. **自动签到**：当天没抽奖就进了游戏？**入服满 5 分钟会自动帮你抽一次**，结果发到游戏内聊天栏。
5. **查看**：`/签到 连续签到` 看连签天数，`/签到 统计` 看累计战绩。

## 二、奖励与概率

每次签到都会抽出一个 **0–999 的幸运数字**，数字落在哪一档决定你拿到什么：

| 连续签到天数 S | 幸运数字落入 | 奖励 |
|---|---|---|
| S < 7 | 0–59（概率 **6%**） | 海洋之心 ×1（不可交易） |
| S < 7 | 60–999 | 金币 = 幸运数字（60–999） |
| S ≥ 7 | 0–99（概率 **10%**） | 海洋之心 ×1（不可交易） |
| S ≥ 7 | 100–999 | 金币 = 幸运数字 + 连签加成 |

**连签加成**：每满 7 天连签，金币奖励 +100，可无限叠加：

| 连签 S | 加成 | 金币实际区间 |
|---|---|---|
| 1–6 | +0 | 60–999 |
| 7–13 | +100 | 200–1099 |
| 14–20 | +200 | 300–1199 |
| 21–27 | +300 | 400–1299 |
| … | 每 7 天 +100 | 依此类推 |

抽到金币时回复形如：`恭喜你Alice，你抽到了223金币(连续签到奖励+100)，奖励已发放。你的幸运数字是123。连续签到8天！`

### 奖励发放方式

- **海洋之心**：直接发放 1 颗**不可交易**的比特海洋之心（不是实体物品，不必领取），游戏内可用 `/比特海洋之心`（`/bithexgem`）查看与使用。
- **金币**：直接入账，离线也能到账。

## 三、连续签到规则

- 连签天数从**今天**往回逐日累加，中间断一天即中断。
- **断签无任何惩罚**：不清零资产、不降级，只是连签归 1、失去概率与加成福利。
- **没有补签机制**，也没有每周/每月的特殊签到奖励。
- 每天 0 点后（以服务器时间为准）即可重新签到。

## 四、命令一览

| 命令 | 说明 |
|---|---|
| `/签到` | 当日抽奖（别名：`今日抽奖`、`每日抽奖`、`抽奖`；不带 `/` 也可用） |
| `/签到 连续签到` | 查看当前连签天数（今天未签则显示 0；≥7 天会提示概率已提升） |
| `/签到 统计` | 累计领取次数、金币累计与平均、海洋之心次数与占比、最近连续相同奖励 |
| `/签到 排行榜` | 尚未实装（回复「排行榜功能开发中」） |

重复抽奖会回复：`你今天已经抽过了，你抽的东西是：<今天的奖励>`。

### 统计口径说明

- 金币的「累计/平均」只统计基础金额，**不含连签加成**。
- 今天的签到要等到明天才会计入统计。
