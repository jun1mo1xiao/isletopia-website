# 群内小游戏 · 模拟炒股

模拟炒股不是「虚拟股票池 + 随机涨跌」的玩具，而是**锚定真实 A 股与港股行情**的模拟交易：你用服务器金币，按真实的周收盘价买卖贵州茅台、腾讯控股等真实股票。每周五傍晚开盘、周日深夜封盘，周一到周四休市时还能参与大盘涨跌竞猜。买卖手续费注入全服奖池，每周结算发给周收益榜前三名。

## 一、游玩流程总览

1. **前置条件**：完成 QQ 绑定（见[QQ 机器人绑定系统](../QQ群功能/QQ机器人绑定.md)）。指令**仅在 QQ 群可用**（别名：`炒股`、`股票`、`stock`）。
2. **选股票**：`/炒股 列表` 获取股票目录网址；或直接 `/炒股 行情 贵州茅台` 查询。A 股支持全市场 6 位代码（如 `600519`），港股限恒生指数成分股（如 `hk00700`）。
3. **买入**：交易窗口（**周五 18:00 – 周日 23:00**，北京时间）内 `/炒股 买入 贵州茅台 50000`，按**本周最后交易日的真实收盘价**立即成交。
4. **持有**：持仓按真实行情随周波动，分红送转换算自动折算（见估值公式）。**T+1 周**——买入当周不能卖出，最快下周五开盘后才能卖。
5. **卖出**：`/炒股 卖出 腾讯 全部`，盈亏落袋，手续费入奖池。
6. **竞猜**：周一 00:05 – 周四 23:59，`/炒股 竞猜 涨 3000` 押注下周上证指数涨跌。
7. **结算**：每周五新行情确认后结算连红、发放奖池，并向 QQ 主群推送开盘公告。

## 二、可交易范围

- **A 股**：全部沪深 A 股（沪市 `60xxxx`、深市 `00xxxx`/`30xxxx`），代码可不带 `sh`/`sz` 前缀，系统会自动补全。
- **港股**：仅限**恒生指数成分股**（约 80–110 只，随恒指检讨变动），代码形如 `hk00700`。
- 支持按名称交易：精确代码 > 名称完全匹配 > 模糊匹配；名称含繁简映射（输入「腾讯」可命中「騰訊控股」）；歧义时列出最多 10 个可点击候选。
- 股票目录网页：`/炒股 列表` 返回完整目录链接（代码 + 名称 + 市场）。

## 三、价格机制：真实行情，无随机

价格全部来自真实市场，**没有随机涨跌**：

- 系统自动从公开行情获取真实价格，每周确认新的收盘价后全服统一更新（下文称这次更新为「换周」）。
- 一个交易周内价格固定不变；换周即相当于「新一周开盘」。
- 不设涨跌停，也没有买卖冲击成本；停牌股按最后已知价估值，既不能买入也不能卖出。
- 行情长时间未更新时，系统会暂停新的买入（卖出不受影响）。

## 四、市值怎么算（分红如何处理）

持仓不记「股数」，只记**投入本金**与**买入周**。你的市值按真实价格的涨跌等比缩放：

- 买入价按**含分红折算**的价格计算；
- 之后每次分红、送转都会自动折算进收益，不需要你手动处理，也不会出现「除权跳水」的假亏损。

例如：买入周茅台折算价 1549.02，本周收盘 1275.16，市值就是本金的 1275.16 ÷ 1549.02 倍（约 −17.68%）。

- 加仓同一只股票会合并为一条持仓，买入周更新为本周；
- 港股统一以人民币记账，展示市值时按当周汇率折算成港元。

## 五、交易规则

| 规则 | 数值 |
|---|---|
| 交易窗口 | 周五 18:00 – 周日 23:00（含边界） |
| 最小买入 | ¥1,000 |
| 单笔买入上限 | ¥500,000 |
| 最大同时持仓 | **10 只**（加仓已有持仓不占名额） |
| 每窗口委托数 | **10 笔**（买 + 卖合计） |
| 手续费 | 买、卖各 **0.15%**（注入全服奖池） |
| 卖出限制 | **T+1 周**（买入当周不可卖）；停牌股不可卖 |
| 杠杆/做空/印花税 | 无；亏损上限 = 本金 |
| 冻结交易 | 管理员可冻结（只禁买、不禁卖） |

### 买入

扣款 = 金额 + 手续费（¥10,000 买入实扣 ¥10,015）。买入需要同时满足：处于交易窗口、该股本周有行情、金额在 ¥1,000–¥500,000 之间、本周委托数与持仓数未超限、余额充足。

### 卖出

- 金额可省略或填 `全部`（= 100%）；请求金额超过市值时按全卖处理。
- 卖出按比例结算（金额四舍五入到分）：先确定要卖出的市值比例，据此得到成交金额，扣掉 0.15% 手续费后到账；本次盈亏 = 到账金额 − 对应比例的本金。
- 例：本金 10000、市值 12000 时全卖 → 成交金额 12000、手续费 18、到账 11982、盈利 1982（+19.82%）。

### 本周盈亏怎么算

本周盈亏 = 当前持仓市值 − 本周基准。买入或卖出时会自动校准基准（买入加上金额、卖出减去成交金额），所以周中的买卖不会让本周盈亏凭空变化。每周换周后会结算一次，并重新设定新一周的基准。

## 六、周结算、连红与退市

- **每周换周时结算一次**：持仓市值不低于上周基准就算**盈利周**（持平也算盈利），连红 +1；否则连红清零。当周清仓的玩家记为亏损周。
- **退市强平**：持仓股票被移出股票池（例如恒指检讨调出）时，会按最后已知市值强制平仓，金币自动到账并通知。

## 七、排行榜、称号与奖池

### 三个榜单（`/炒股 排行 [周|总|连红]`，各取前 10 + 个人名次）

| 榜 | 口径 | 上榜门槛 |
|---|---|---|
| 周收益榜（默认） | （当前持仓市值 − 上周基准） ÷ 上周基准 | 上周基准 ≥ ¥10,000 |
| 总收益榜 | （已实现盈亏 + 浮动盈亏） ÷ 累计投入 | 累计投入 + 当前持仓 ≥ ¥10,000 |
| 连红榜 | 当前连续盈利周数 | ≥ 2 周 |

称号（仅展示）：周榜第 1「👑 本周股神」、总榜第 1「👑 常胜将军」、周榜倒数第 1「🌚 本周反指」。

### 手续费奖池

- 买卖手续费全部注入全服奖池。
- 每周开盘公告时结算：周收益榜**前三名按 50% / 30% / 20%** 分走奖池（发奖总额不超过池内余额）；不足 3 人时余款留在池中滚存。

## 八、大盘竞猜

- **窗口**：周一 00:05 – 周四 23:59。
- **下注**：`/炒股 竞猜 <涨|跌> <金额>`，单笔 ≥ ¥100，同一轮累计 ≤ ¥5,000；**同一轮不能改方向**（可同方向加注）。
- **判定**：比较本周与下周**上证指数的收盘点位**，涨/跌/平。
- **派奖**：猜中者按下注比例瓜分整池（币中性，系统不抽成）；**无人猜中或平盘时奖池清零沉淀**（不退不滚存）。
- 竞猜连中次数计入个人战绩。
