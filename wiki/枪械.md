# 枪械

**枪械**是一整座岛的开关：岛主开启后，岛上的枪械才能正常使用。没开启的岛上，带过去的枪会显示成普通物品，也完全打不出去；离开后自动恢复，物品不会丢失。

## 一、基本操作

| 操作 | 按键 |
| --- | --- |
| 开火 | **右键**（自动枪按住不放会持续射击） |
| 瞄准 / 开镜 | **左键**（再按一次退镜；部分狙击枪可以逐档变焦） |
| 换弹 | **Q**（丢弃键，不会真的把枪丢出去） |
| 切换武器模式 | **F**（换手键，目前只有「胖子」核弹发射器有两个模式） |
| 切换射击模式 | **连续潜行两次**（单发 / 点射 / 全自动，只对支持多模式的枪有效） |

几点说明：

- **空弹匣再按开火会自动换弹**；换弹会强制退镜，装弹过程中不能重新开镜。
- 弹匣里有子弹时，开火会打断换弹；枪机动作没走完时，要先补完动作才能打下一发。
- **大部分枪在疾跑、游泳、副手拿着东西时开不了火**——这是每把枪自己的限制（例如 .50 GS 允许副手持物，手雷等投掷物只限制游泳）。
- 刚把枪拿到手上有一段**举枪时间**（不同枪长短不同），期间开不了火。
- 手雷、闪光弹、火箭筒等爆炸物也在同一个系统里，用右键投掷 / 发射。

## 二、射击模式与武器模式

- **射击模式**：步枪、冲锋枪、机枪等支持多模式的枪，连续潜行两次循环切换单发、点射、全自动；FR 5.56 默认就是三连点射。模式记在枪上，换枪各自保留自己的一套。
- **武器模式**：「胖子」核弹发射器按 F 在**核弹**与**石头弹**之间切换。两个模式的**弹药各自独立**：核弹是大范围爆炸，石头弹直击伤害高、能穿透多个目标，但没有爆炸。

## 三、枪机动作

每把枪的枪机节奏不同：

- **步枪 / 冲锋枪 / 机枪**：套筒动作只在换弹时出现，不影响全自动射速；
- **Kar98k、AX-50（栓动 / 拉杆）**：每打一发都要完成一次拉栓，动作没走完时下一发打不出去；
- **R9-0（泵动霰弹枪）**：每两发泵动一次；
- **.357 马格南左轮**：开膛、合膛在换弹时进行。

## 四、岛屿限制

- 枪械只在**开启开关的岛**上生效；没有开启的岛上，枪械模型消失、无法开火 / 换弹 / 瞄准，和普通物品没有区别。
- 岛上的「禁止发射弹射物」开关会让枪完全打不出去；「禁止 PvP」开关开启时，子弹打玩家不掉血。
- 本岛枪械的开启 / 关闭由岛主执行 `/ToggleGun`。
