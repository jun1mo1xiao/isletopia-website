# 岛屿

梦幻之屿提供十余种岛屿类型，每种类型都是一套独立的玩法预设：不同的世界构成、核心机制与启用特性。本页是总览，点击类型名称进入详细介绍。

## 常规类型

这些类型共享同一套通用特性（挑战、幻形、祈愿、云仓等），差异在于核心玩法。

| 类型 | 一句话介绍 |
| --- | --- |
| [经典空岛](/wiki/空岛类型/经典空岛) | 标准空岛生存，全特性，服务器的主玩法 |
| [单方块空岛](/wiki/空岛类型/单方块空岛) | 从一个无限刷新的方块开始一切 |
| [随机空岛](/wiki/空岛类型/随机空岛) | 全岛每 2 分钟变成一种随机方块 |
| [九选一空岛](/wiki/空岛类型/九选一空岛) | 3×3 平台，挖一格全刷新，搏宝箱 |
| [钓鱼空岛](/wiki/空岛类型/钓鱼空岛) | 收杆必出货，钓出整个世界的悠哉开局 |
| [假日海岛](/wiki/空岛类型/假日海岛) | 划船探索 54 个群系主题群岛与沉船 |
| [地底世界](/wiki/空岛类型/地底世界) | 石头包裹的地底洞穴生存，挖矿为主题 |

## 专家模式

独立存档档案、更高的生存压力与专属挑战链，面向有经验的玩家。

| 类型 | 一句话介绍 |
| --- | --- |
| [困难空岛](/wiki/空岛类型/困难空岛) | 李芒果式硬核空岛，几乎万物可再生但一切从零开始 |
| [海底求生](/wiki/空岛类型/海底求生) | 主世界全是水，从一艘破沉船开始的深海生存 |
| [惊变空岛100天](/wiki/空岛类型/惊变空岛100天) | 4 人小队 100 天生存挑战，带淬炼与难度解锁链 |
| [极限生存挑战](/wiki/空岛类型/极限生存挑战) | 独立存档、只有一条命的高难生存挑战 |

## 创建规则

- 打开路径：按 **G 键**打开服务器根菜单 → 「岛屿菜单」→「创建岛屿」；也可用 `/openDialog /islands` 直接打开。
- 在创建对话框中选择类型并填写岛名（最长 50 字）；部分类型有额外选项（如经典空岛的「开启刷石机出矿」）。
- **第一座岛屿免费**；创建第二座及以后，每座消耗 **1 颗海洋之心**。
- 除注明外，初始物资为：水桶 ×2、岩浆桶 ×1、苹果 ×64。
- 每座岛屿有独立的主世界、下界、末地三个维度。
- 部分类型对创建者有额外要求：多人生存（SMP）需完成空岛挑战前三级；鸡因空岛、惊变空岛100天等仅限管理员/白名单创建（见[特殊岛屿](/wiki/空岛类型/特殊岛屿)）。
